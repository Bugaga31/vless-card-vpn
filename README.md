# VLESS Card VPN

**VLESS + Reality клиент для Android с карточным интерфейсом**

[![Android](https://img.shields.io/badge/Android-8.0+-green.svg)](https://developer.android.com)
[![Sing-box](https://img.shields.io/badge/sing--box-Reality-blue.svg)](https://sing-box.sagernet.org)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

VLESS Card VPN — современное Android-приложение для обхода DPI с использованием протокола VLESS + Reality. Красивый карточный UI, автоматическое тестирование серверов, умная маршрутизация (российские ресурсы напрямую), адаптивная маскировка под сеть и поддержка бесплатных/публичных VLESS-конфигов.

Приложение полностью открытое, без серверной инфраструктуры, использует стандартный sing-box в качестве ядра.

## Возможности

- **Карточный интерфейс**: Material3-карточки серверов с пингом, статусом, временем теста. Tap для подключения.
- **Автотест**: Фоновые тесты пинга и TLS-хендшейка, автосортировка по скорости, пометка нерабочих.
- **Split routing (RU-direct)**: Все .ru домены, geoip:ru, geosite:category-ru и приватные IP — напрямую. Остальное — через VLESS.
- **Network-aware Masking**: Автоопределение сети (мобильный интернет / Wi-Fi). На мобильной связи (МТС, Билайн, Теле2, Мегафон) — SNI yandex.ru / music.yandex.ru. На Wi-Fi — samsung.com или другие. Динамический выбор в SingBoxManager.
- **Импорт бесплатных VLESS**: Кнопка «Добавить бесплатные», кураторский список публичных подписок (пользователь вставляет URL), автоимпорт + тест. Только Reality VLESS.
- **Сильная маскировка Reality**: xtls-rprx-vision + uTLS chrome fingerprint. Трафик выглядит как обычный HTTPS Yandex.
- **Безопасность**: Нет логирования трафика, kill-switch, регулярное обновление geo-ассетов.
- **Нет проприетарных серверов**: Только ваш VPS + sing-box / 3X-UI.

## Как работает маскировка

Приложение автоматически выбирает SNI в зависимости от типа сети:

- **Мобильный интернет (4G/5G)**: MTS, Beeline, Tele2, Megafon и др. → использует `yandex.ru` или `music.yandex.ru` (лучше всего проходит DPI у российских операторов).
- **Wi-Fi**: `samsung.com` или другие популярные SNI (менее подозрительно для некоторых провайдеров).

Сеть определяется через `ConnectivityManager` + `TelephonyManager` (оператор). SNI можно задать глобально или per-конфиг.

Reality-хендшейк:
1. Клиент отправляет обычный ClientHello с SNI yandex.ru.
2. Сервер (используя приватный ключ Reality) подписывает временный сертификат.
3. xtls-rprx-vision убирает второй слой TLS для скорости и меньшего fingerprint.
4. DPI видит только легитимный трафик к yandex.ru:443.

Дополнительно: uTLS chrome fingerprint, короткий shortId, правильный public key.

## Как добавить бесплатные / публичные VLESS-конфиги

1. Нажмите кнопку **«Добавить бесплатные»** в верхней панели.
2. Откроется список проверенных публичных подписок (2026 год, RU-friendly).
3. Вставьте URL подписки (например, из GitLab-репозиториев или Telegram-каналов, которые публикуют бесплатные Reality VLESS).
4. Приложение скачает, распарсит только `vless://` ссылки **с параметрами Reality** (`security=reality`, `pbk`, `sid` и т.д.).
5. Автоматически проведёт тест (пинг + TLS).
6. Только валидные Reality-конфиги добавятся в карточки.

**Примеры санитизированных ссылок (не используйте напрямую — ищите актуальные):**
- `https://raw.githubusercontent.com/.../vless-reality-sub.txt`
- Подписки из открытых репозиториев вида `gitlab.com/vpn-configs-for-russia/...`

**Важно**: Приложение строго валидирует только Reality VLESS. Обычные VLESS или Trojan игнорируются.

## Быстрый старт

### 1. Подготовка сервера (VPS)

Рекомендуется VPS в Европе (Нидерланды/Финляндия) с Ubuntu 24.04.

**Вариант A — 3X-UI (самый простой)**:
1. Установите 3X-UI.
2. Создайте Inbound:
   - Protocol: VLESS
   - Port: 443
   - Flow: xtls-rprx-vision
   - TLS: Reality
   - Server Name (SNI): `yandex.ru`
   - Destination: `yandex.ru:443`
   - uTLS: `chrome`
   - Short ID: `01` (или `sing-box generate rand 8 --hex`)
   - Private Key: `sing-box generate reality-keypair`
   - UUID: новый

**Вариант B — ручной sing-box**:
См. полный пример в файле `VLESS_Card_VPN_Design.md`.

Генерация ключей:
```bash
sing-box generate reality-keypair
sing-box generate rand 8 --hex
```

### 2. Сборка APK

```bash
# Клонируйте проект
git clone <repo>
cd vless-card-vpn

# В Android Studio или:
./gradlew assembleRelease
```

APK будет в `app/build/outputs/apk/release/`.

### 3. Установка и использование

1. Установите APK (разрешите неизвестные источники).
2. Добавьте конфиг:
   - Кнопка + → вставьте `vless://...`
   - Или «Добавить бесплатные» → вставьте подписку.
3. Нажмите **Test** на карточке.
4. Нажмите **Connect** — запустится VPN с split-routing.
5. Русские сайты работают напрямую, остальное — через прокси.

Автотесты запускаются в фоне.

## Как пользоваться карточками, тестами и подключением

- **Список серверов**: Карточки с названием, адресом, пингом (цвет: зелёный <80мс, жёлтый, красный).
- **Статус**: зелёный — подключено, синий — живой, красный — мёртвый.
- **Тест**: Кнопка «Test» или «Test All» — проверяет TCP + TLS-хендшейк с правильным SNI.
- **Подключение**: Tap по карточке или кнопка Connect. Активная подсвечивается.
- **Импорт подписок**: Поддерживаются base64-подписки, фильтруются только Reality VLESS.
- **Настройки**: Можно выбрать глобальный SNI или сеть-зависимый.

При отключении всех серверов — автопереключение на direct + предупреждение.

## Детали шифрования (кратко)

- **Протокол**: VLESS + Reality + xtls-rprx-vision
- **TLS**: 1.3 + HTTP/2
- **Fingerprint**: uTLS chrome (максимально похоже на браузер Chrome)
- **Reality handshake**:
  - Клиент отправляет обычный TLS ClientHello с SNI (yandex.ru).
  - Сервер проверяет с помощью приватного ключа и выдаёт временный сертификат.
  - xtls-rprx-vision убирает лишний TLS-слой → быстрее и меньше отпечаток.
- **Параметры**:
  - `pbk` — публичный ключ сервера
  - `sid` (shortId) — короткий идентификатор (обычно 2-8 hex)
  - `sni` — маскировочный домен
  - `fp=chrome`
- Результат: DPI видит обычный HTTPS-трафик к yandex.ru. Никаких признаков прокси.
