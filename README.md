# VLESS Card VPN 🎃

**Ваши подключения. Ваши настройки. Ваш выбор.**

Android-клиент на Xray-core помогает подключаться по вашим конфигурациям, искать подходящий маршрут и проверять доступность нужных сайтов. А когда связь сбивается — пытается её восстановить.

[📥 Скачать последнюю версию](https://github.com/Bugaga31/vless-card-vpn/releases/latest) · [🚀 Быстрый старт](#-быстрый-старт) · [🔒 Безопасность](#-данные-и-безопасность) · [💬 Сообщить о проблеме](https://github.com/Bugaga31/vless-card-vpn/issues)

> Проект развивается. Успешная проверка в одной сети не гарантирует работу на любом устройстве, операторе или сервере.

## ✨ Возможности

- **Авто и проверка маршрутов** — подбор с учётом текущей сети и проверками через маршрут. Задержка и скорость — разные показатели.
- **Ваши конфигурации** — поддерживаемые Xray-подключения и подписки, раздельное туннелирование, настройки DNS и правила сайтов.
- **Резервирование и восстановление** — подготовка подходящих запасных маршрутов и попытка восстановления при сбоях; переключение может прервать активные запросы.
- **Маски и DPI** — ByeDPI/zapret в поддерживаемых сценариях. Не каждая маска сработает в каждой сети.
- **ВАТСОН** — локальные подсказки и аудит разрешений; это не антивирус и не доказательство слежки.

## 🚀 Быстрый старт

1. Откройте [страницу последнего релиза](https://github.com/Bugaga31/vless-card-vpn/releases/latest). Для большинства современных телефонов подойдёт **ARM64 APK**; универсальный APK — для других поддерживаемых архитектур.
2. Установите APK и, если обновляете Beta2, установите его **поверх приложения**. Перед удалением приложения сохраните и проверьте резервную копию.
3. Добавьте подходящую конфигурацию или подписку, выберите маршрут либо Авто и подтвердите системный запрос разрешения VPN.
4. В релизе **1.2.123** раздел «Что проверять» позволяет выбрать сайты и добавить свой домен через «+». Начните с действительно нужных проверок: большое число сайтов может не успеть провериться за общий срок.

## 🔍 Что означает зелёная проверка?

Успешная HTTPS-проверка подтверждает доступ к проверенной странице через маршрут. Она **не подтверждает** вход в аккаунт, все функции приложения или воспроизведение YouTube. Неопределённый результат — не успех. Подробнее о конкретной версии и её проверках — в [описании релиза 1.2.123](https://github.com/Bugaga31/vless-card-vpn/releases/tag/v1.2.123).

## 🆘 Нужна помощь?

Если что-то не работает, проверьте выбранный сервер, текущую сеть и нужные сайты. Затем откройте [Issues](https://github.com/Bugaga31/vless-card-vpn/issues) и опишите версию приложения, версию Android, тип сети, шаги и текст ошибки.

**Не публикуйте** ссылки на подписки, UUID, ключи, токены, адреса личных серверов и резервные копии. Ошибку Chrome или воспроизведения видео полезно описать отдельно от результата HTTP-проверки.

> **Исходники и релиз:** основная ветка и опубликованный APK могут различаться. Для возможностей конкретного APK и результатов его тестов смотрите соответствующую страницу релиза.

## 🧭 Как устроен проект

Android-клиент на **Xray-core + hev-socks5-tunnel**, с ByeDPI/zapret для поддерживаемых сценариев обхода DPI. Текущая основная ветка не использует старое ядро sing-box, Room Database или языковую модель из ранних экспериментальных APK.

## Основной сценарий
**VLESS Card — подключение через Xray одной кнопкой.** Авто учитывает текущую сеть, проверяет реальный HTTPS и сравнивает короткие изолированные загрузки, когда рабочий маршрут медленный или его скорость неизвестна. Низкий пинг сам по себе не означает быстрое скачивание. Поиск ограничен бюджетом времени; остальные проверки выполняются в фоне, когда это допускают нагрузка, батарея и температура.

Публичное облако поставляет конфигурации и датированные замеры. До двух облачных претендентов получают отдельные места рядом с лучшим локальным маршрутом, а не теряются в конце списка. Телефон подтверждает их в своей сети: зарубежный замер не доказывает обход блокировок у конкретного оператора. При недоступности облака используются кэш и локальная память. Это не гарантия самого быстрого сервера во всём интернете или подключения за фиксированное число секунд.

- VLESS/Reality, VMess, Trojan, Shadowsocks, Hysteria2 и другие поддерживаемые Xray конфигурации.
- Подписки, раздельное туннелирование, DNS-кэш, RU Direct и ручные правила сайтов.
- Самовосстановление, маскировки и ограниченные фоновые волны проверки.
- Общее публичное облако рейтингов/профилей: подсказки должны подтверждаться на конкретном телефоне и операторе. Автоматическая отправка телефонных отчётов отключена; общего write-token в APK нет.
- Отдельное облако резервных копий в личном GitHub — это backup, а не измеритель скорости.
- Отдельная вкладка «Телефон»: системные показания, локальное обучение и рекомендации без root. Не может автоматически ограничивать чужие приложения или физически охлаждать устройство.
- Морской фон с анимацией волн, выключателем и статичным режимом при ограничениях энергии/нагрева/системной анимации. AMOLED остаётся чёрным.

## Совместимость
Текущий minSdk — **Android 7 / API 24**. Датчики и экраны настроек зависят от версии Android и производителя. Релизные ARM APK проверяются в CI на эмуляторах Android 11 и 14 с ARM-трансляцией; это не проверка всех физических телефонов и сетей РФ.

## Сборка
Нужны JDK 17, Android SDK 34/build-tools 34.0.0 и NDK **27.2.12479018**. Xray AAR загружается по закреплённой версии и проверяется SHA-256. Native зависимости собираются из исходников.

```bash
./gradlew --no-daemon --max-workers=2 :app:testDebugUnitTest :app:assembleDebug
```

Для подписанного Beta-релиза используется `.github/workflows/beta-release.yml`: полный native build, JVM-тесты, постоянный ключ подписи из GitHub Secrets, install/Keystore gates на Android 11/14. Ошибки блокируют публикацию. Номер сборки не равен количеству релизных записей; история содержит разные ветки, экспериментальные приложения и повторные публикации.

## 🔒 Данные и безопасность
- Production state и пользовательский GitHub-токен защищены AES-256-GCM/Android Keystore; отдельная телефонная модель хранится зашифрованной, без сырой истории показаний.
- Debug/E2E state может храниться в открытом JSON для тестов. Debug APK не является вариантом для хранения реальных секретов.
- Переносимые ссылки backup и содержимое личного облачного backup **не зашифрованы**: содержат серверные ключи/подписки, хранить только у себя.
- APK перед установкой проверяется по размеру, SHA-256, пакету, версии и сертификату установленного приложения. Android выполняет собственную проверку установки.
- Старый общий ключ из исторических APK требует отдельного отзыва; его удаление из текущего APK не отзывает прошлые копии.
- Работоспособность публичной страницы сервиса не гарантирует доступность аккаунта, региональных функций или высокую скорость.

## Windows: начальный Xray preview
Отдельный проект `desktop/`: портативный Windows x64 EXE с локальным SOCKS5, импортом VLESS TCP/TLS/Reality и публичным облаком. Это пока **не** системный VPN/TUN и не полный перенос Android-автоподбора. Системный прокси не меняется. Возможности и ограничения — `desktop/README.md`; сборка и smoke-тест — `.github/workflows/windows-preview.yml`.
