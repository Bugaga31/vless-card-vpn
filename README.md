# VLESS Card VPN

Мощный и легкий Android VPN-клиент на базе современного нативного ядра **sing-box / libbox**, оптимизированный для обхода блокировок ТСПУ/DPI с поддержкой протоколов **VLESS Reality**, **XTLS Vision**, **VMess**, **Trojan** и **Shadowsocks**.

---

## ⚡ Особенности и Архитектура

- **Нативное ядро `sing-box` (libbox)**: Прямая интеграция через `VpnService`, перехват сокетов, zero-copy TUN FD, сбор реальной сетевой статистики (входящий/исходящий трафик и битрейт в реальном времени).
- **VLESS Reality + XTLS Vision**: Настоящая маскировка TLS-рукопожатия под белые списки (`yandex.ru`, `vk.com`, `samsung.com` и др.) с генерацией валидных отпечатков Chromium / Firefox / Safari.
- **Обход замедления YouTube**: Встроенный сплиттер с блокировкой QUIC (UDP:443) для перенаправления видеопотока через быстрый оптимизированный TCP/TLS-канал без буферизации.
- **Раздельное туннелирование (RU Direct)**: Госуслуги, банки, Ozon, Wildberries и домены `.ru`/`.su` направляются напрямую без VPN-оверхеда (0 ms latency).
- **Автопилот (Failover Engine)**: Автоматический мониторинг здоровья активного туннеля. При 3 подтвержденных потерях пакетов автопилот бесшовно переключает соединение на самый быстрый резервный узел.
- **Интеллектуальный MTU**: Начальный MTU 1400 с адаптивной подстройкой при фрагментации мобильных операторов (МТС, Билайн, Мегафон, T2/Tele2).
- **Персистентность (Room Database)**: Полное локальное сохранение серверов, избранного и настроек с защитой данных.
- **Киберпанк Cockpit UI**: Неоновый интерфейс с 3D-глобусом, спидометром, быстрой проверкой Telegram/YouTube/РКН и кнопкой экстренного разрыва («Panic Button»).

## 🛠️ Сборка проекта (Build Instructions)

### Требования:
- JDK 17+ (или OpenJDK 21)
- Android SDK 34 (Android Build Tools 34.0.0)
- Gradle 8.7

### Локальная сборка:
```bash
# Клонирование репозитория
git clone https://github.com/Bugaga31/vless-card-vpn.git
cd vless-card-vpn

# Сборка Debug APK
./gradlew assembleDebug

# Запуск Unit-тестов
./gradlew testDebugUnitTest
```
