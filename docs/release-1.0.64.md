## Скачайте один файл: **VLESS-Card-Beta-1.0.64.apk**
Ставится **поверх** 1.0.63, серверы и настройки сохраняются.

### WARP: новая маскировка WireGuard
Раньше у WARP было всего 4 вида шума. Теперь 23 маски, и подбираются они сами:
- **Шум как в AmneziaWG:** 4 мусорных пакета по 40–70 байт или 10 пакетов по 50–1000 байт перед рукопожатием.
- **Шум, похожий на разрешённый трафик:** QUIC (HTTP/3 браузера), DTLS (видеозвонок), голос RTP.
- **Прыжки по портам:** каждые 10–20 секунд меняется локальный порт, и для DPI это новое соединение. Для WARP можно ещё прыгать по 54 портам Cloudflare, чтобы не было одного потока, который можно заметить и заблокировать.
- **Сочетания шума и прыжков.** Подбор останавливается на первой рабочей маске для каждого аккаунта.
- **Регистрация WARP**, если API Cloudflare заблокирован, повторяется через обход DPI для этой сети и через работающее подключение (теперь и со скрытым паролем).

### Маскировка учится на твоей сети
- Приложение запоминает, какие маски сработали и какие не сработали в этой сети (отдельно для Wi-Fi и для «Моб.: Beeline»). При следующем подборе для любого сервера сначала пробуются маски, которые уже работали, а заведомо нерабочие идут в конец.
- Провалы на мёртвом сервере (где не сработало ничего) статистику масок не портят.

### Фоновое ускорение, без кнопок (Настройки → «Фоновое ускорение», включено)
- **При запуске**, пока VPN выключен, приложение само обновляет подписки, проверяет серверы и подбирает маски, чтобы «Подключить» срабатывало сразу. На мобильном интернете проверяет меньше серверов и без больших загрузок.
- **Во время подключения**: через 3 минуты, а потом раз в 20 минут проверяет выбранные серверы и лучшие из остальных в обход туннеля. Если выбранный сервер умер или есть заметно более быстрый (в 1,6 раза и больше), переключается сам. Если не работает ничего, заново подбирает маски.
- Аккаунты WARP с одним ключом никогда не выбираются одновременно.

### Быстрее
- Результаты проверки записываются пачками. Раньше при 10 000 серверов каждая запись копировала весь список, отсюда тормоза при проверке и в списке серверов.
