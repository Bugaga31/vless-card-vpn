# VLESS Card 1.2.10

- **Облако правильно переключается вместе с сетью.** Телефон сохраняет данные всех операторов и применяет нужные при смене Wi-Fi/мобильной сети, даже если версия облака не изменилась или интернет временно недоступен. Для неизвестного оператора старые оценки блокировок не используются.
- **Свежие скорости каждые 10 минут при подборе серверов.** Вместо часового кеша — десятиминутный и ETag: без изменений полный файл не скачивается. При ошибке повторная попытка не чаще раза в минуту; сохранённые данные остаются доступны.
- **Надёжнее загрузка облака.** Некорректный ответ не сохраняет ETag, который мог мешать повторной загрузке. Пустые актуальные данные очищают устаревшие оценки и нагрузку.
- Изменение `cloud_real.py` теперь тоже запускает облачную проверку. Планировщик GitHub задан на 10 минут, но фактический запуск может задерживаться на стороне GitHub.
- Добавлены регрессионные тесты смены сети, неизвестного оператора, срока кеша, повторных попыток и перевода часов назад. Проверка реального телефона и сетей РФ отдельно необходима.
