# Ограничение UI-артефакта 1.2.55

Выпуск v1.2.55, SHA b83abbf3a5db185b09e74032b0e4df6efb0a28aa опубликован;
подписанные APK и тег этим исправлением не заменяются.

При ручном просмотре опубликованных PNG установлено: Android-home-api-30.png
показывает главный экран, Android-home-api-34.png — заставку. Последний файл
ошибочно назван home. Это не доказательство дефекта подключения или установки,
но и не подтверждение главного экрана API 34.

Прежний gate «непустой PNG + четыре текстовых элемента приложения» пропускает
заставку. Новый gate требует реальные элементы «Подключить», «Главная», «Серверы»
и отсутствие кнопки заставки «Открыть приложение». Добавлены четыре регрессии,
включая главный экран под заставкой. Nonblank PNG gate и проверки запуска сохранены.

Изменение находится в отдельной fix-ветке; на эмуляторе оно пока не проверено.
Физический телефон этим не проверялся. Нельзя считать эту ветку изменением уже
опубликованного APK или исправленным скриншотом текущего релиза.
