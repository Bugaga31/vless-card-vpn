# ВАТСОН: ограниченные FlyWire-эксперименты

Используется существующий граф ROKI: 516 узлов, 11517 сохранённых направленных связей из Betzel et al. (2026), Zenodo 18555170, CC BY 4.0. Нормализованные положительные веса, tanh и искусственные входные/выходные адаптеры не являются полной биологической моделью.

## Ссылки

Отдельный readout действительно обучен на историческом PhiUSIIL (Prasad & Chandra, 2024, UCI, CC BY 4.0). 23 локальных лексических признака + 16 выходов резервуара + bias. Исходный алгоритм разделения по регистрируемым доменам сохранён: train/validation/test не пересекаются по доменам. Порог выбран только на validation; тест не используется для настройки. Модель дополнительно предупреждает, но не отменяет предупреждение исходной модели. Это не антивирус, не оценка содержимого сайта и не гарантия обнаружения актуальных угроз. Примеры URL не посещаются.

Обучение: tools/watson-fly/train.py; исходные данные в /data/raw и производные признаки с подтверждённым хешем в /data/analysis; веса, cross-language fixtures и ограничения в model.json/evidence.json. Для независимого воспроизведения сначала запустить feature_baseline.py на исходном UCI CSV и PSL, затем train.py. Изменение очищенного датасета требует заново согласованного split, а не подгонки по test.

## Датчики телефона

Новый readout начинает без опыта. Обучается только на последующих показаниях через 60–180 секунд; после длительного сна прежний пример не размечается. Для готовности нужны минимум 30 размеченных наблюдений и обе категории. Предсказывает только нагрев/нехватку памяти — не расход энергии и не вредоносность. Старый зашифрованный PhoneLearning сохраняется при миграции. Сырые показания не сохраняются. Ошибка открытия не удаляет модель.

Советы не меняют VPN, число параллельных проверок, маски, права других приложений, частоты процессора и сетевые маршруты. Измеренная экономия батареи и безопасность на реальных телефонах НЕ подтверждены. Фоновая диагностика остаётся отдельной добровольной настройкой.
