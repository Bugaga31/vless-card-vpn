# VLESS Card 1.2.66 · Experimental

## Изменения

- Быстрый поиск сначала проверяет до восьми подходящих маршрутов параллельно и начинает подключение после первого успешного HTTPS-ответа — без ожидания скачивания контрольного файла и предварительного TCP-опроса.
- Цель быстрой попытки — около пяти секунд, если сохранённый маршрут отвечает. Если готового маршрута нет, приложение продолжает поиск; время зависит от сети и доступности источников.
- Незавершённая проверка больше не помечает серверы как уже проверенные. Ошибочный источник подписки повторно запрашивается через 20 секунд вместо 60.
- Автопрофиль Tor допускает реалистичную задержку HTTPS до 6 секунд в Wi-Fi и 7,5 секунд в мобильной сети, чтобы не отбрасывать рабочие, но более медленные Tor-выходы.
- Проверка состояния Tor автоматически обновляется при подключённом VPN; исправлен выбор ControlPort для встроенного Tor и Termux.
- Главный экран показывает цель быстрого подключения и отдельно предупреждает, что построение первой Tor-цепочки может занять дольше пяти секунд. Расширенные настройки Tor свёрнуты по умолчанию.

## Проверки

По запросу функциональные тесты, lint, эмулятор и физическое устройство не проверяются. Сборка и подпись APK нужны только для выпуска установочных файлов; при подготовке релиза выполняются проверки целостности APK и постоянного Beta-сертификата.
