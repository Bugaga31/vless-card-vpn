# 1.2.110 Experimental — кандидат, не опубликован

- Временные SOCKS-входы Xray testConfig теперь разрешают UDP и возвращают loopback-адрес реле. Раньше udp=false блокировал саму возможность STUN-проверки через эти входы. Основной VPN-конфиг и серверные ключи/транспорты не меняются.
- Выбранные YouTube/UDP/Discord стартуют параллельно с базовым HTTPS, а не после его ожидания. Общий монотонный deadline и отмена сохраняются. Большой необязательный download по-прежнему стартует после HTTPS.
- Discord в Авто подтверждает API и анонимный WebSocket HELLO с положительным heartbeat_interval через тот же SOCKS. Нет Identify/токена аккаунта/голосового сеанса. Старое API-only доказательство не используется как новое HELLO-доказательство; ручной heartbeat/ACK-тест не удалён.
- YouTube: ограниченный разбор до 2 МиБ вместо 1 МиБ поддерживает поздний player response; распознанный LOGIN_REQUIRED/UNPLAYABLE завершает discovery раньше чтения лишнего HTML с отдельным объяснением. Без 128 КиБ реальных видеобайтов с валидными заголовками нет Pass. JS signature decipher, вход в аккаунт и универсальная совместимость не реализованы.
- Telegram/DC/устойчивость, сертификаты, SNI, ключи, выбранный параллелизм и маски не менялись. Неизвестный обязательный сервис не становится успешным. UDP STUN не доказывает реальный звонок.

## Проверки

Локально на JDK 17/Kotlin 1.9.24: 28 JVM-тестов — 12 новых, 12 ServiceErrorsR220 и 4 ServiceMediaR217. Новые включают настоящий loopback WebSocket Upgrade/HELLO и UDP SOCKS association с 20 ответами, отмену, timeout, отрицательные протокольные случаи и поздний player. Отдельные конфигурационные/кэш/source-wiring регрессии выполняются в проектном CI; это не Android-скриншоты и не полный TUN.

Физический телефон, аккаунт YouTube/Discord, живые звонки, оператор/DPI и экономия батареи не проверены. На публичном стенде YouTube вернул LOGIN_REQUIRED, поэтому реальное воспроизведение со стенда не доказано; Discord API вернул HTTP 200. Ни один из этих ответов не измеряет сеть владельца.

Личное GitHub-облако создано отдельно приватным. Данные с телефона появляются только после явного сохранения; токен не включается в код или резервную копию.
