# VLESS Card 1.1.2

**Google и сайты «без сети» / медленно — исправлено.**
- Переключение серверов (сторож сервисов) раньше могло перейти на сервер, который когда-то работал, а сейчас уже нет, — после этого переставало грузиться всё. Теперь запасные серверы перед переключением проверяются прямо сейчас, и переход идёт только на прошедшие проверку. Если не открывается вообще ничего — это не повод менять серверы (этим занимается починка), сторож не вмешивается.
- После внутреннего переподключения VPN мог полностью пересобираться по ошибке — пока туннель пересобирается, браузер на секунду пишет «нет сети». Теперь перед пересборкой приложение ждёт 3 секунды и проверяет ещё раз; без интернета у самой сети пересборки не будет вообще.
- Сторож теперь следит и за браузерами (Chrome, Samsung Internet, Яндекс, Firefox, приложение Google): если Google не открывается через текущие серверы — переключает на проверенные, где открывается.
