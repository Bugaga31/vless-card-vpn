## Восемь маршрутов в Авто: исправлено сужение и применение пула
- Цель Авто — 8 проверенных рабочих маршрутов, а не ограничение всего каталога восемью. Если прошли проверки меньше восьми, количество не подделывается: пополнение продолжается порциями.
- Одна удачная проверка Telegram/YouTube больше не выбрасывает остальные HTTPS-рабочие маршруты с ещё неизвестным статусом сервисов. Подтверждённые текущие отказы сервисов по-прежнему учитываются.
- Изменение выбранного набора теперь действительно вызывает применение конфигурации Xray; отложенное применение повторяется, сравнивая выбранный пул с запущенным. Ранее обновление списка могло не сопровождаться изменением туннеля.
- Xray в Авто получает скоростные веса по последовательным измерениям именно этой сети/маски. Маленький пинг медленного узла сам по себе не побеждает быстрый. Все восемь outbounds входят в наблюдаемый пул; трафик предпочитает сопоставимые по скорости живые маршруты. Это не объединение восьми каналов: TCP-соединение не переносится бесшовно между серверами.
- Первый фоновый проход для неполного пула запускается через пять секунд после успешного подключения; затем неполный пул проверяется с паузами. Лёгкая проверка доступности не блокируется только из-за тарифицируемой сети/текущего трафика. Тяжёлые замеры скорости всё ещё откладываются при нагрузке, экономии и нагреве.
- Облако публикует происхождение публичных конфигураций: source-map.json, sources у узлов манифеста и source-stats.json. Приватные подписки с телефона не выгружаются. Происхождение различает конфиги с разными учётными данными на одном адресе.
- Телефон учится по локальной успешности/скорости источников в текущей сети и предлагает другие конфиги из результативных подписок для проверки. Это приоритет кандидатов, не выдуманная доступность и не нейросеть. Облачный быстрый кандидат получает отдельный слот сравнения даже при более высоком пинге.
- Добавлена E2E-регрессия, проверяющая реальный запуск восьми Xray outbounds, а не только отметки в списке.

Облако проверяет из сети GitHub, а не от вашего оператора. Скорость на телефоне, работу Telegram и видео YouTube нужно проверять на устройстве. Переконфигурация может перезапустить существующие соединения; это не обещание бесшовного переноса сессий.
