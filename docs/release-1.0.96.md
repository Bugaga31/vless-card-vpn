# VLESS Card 1.0.96 — «Почему не работает?», «заморозка» 16 КБ, темы

- «Почему не работает?» (Настройки и Помощник: «почему не работает», «диагностика»): находит причину, а не просто «ошибка». Для каждого сервера напрямую: не находится имя (DNS), заблокирован по IP (маски не помогут — нужен другой сервер / CDN / WARP), режется по имени сайта SNI (помогут маски с дроблением и SNI разрешённого сайта) или режется TLS к этому IP. Плюс проверка белых списков. Идеи из открытых проектов RIPDPI и tspu-probe.
- «Заморозка» 16 КБ: на мобильном интернете ТСПУ останавливает загрузки с IP хостингов после ~16 КБ. Автопилот раз в 2 часа (и через ~10 минут после смены сети) скачивает через VPN 256 КБ; если загрузка замерла — пишет об этом и сам ищет сервер и маску без заморозки.
- Оформление: тёмная тема, AMOLED (чистый чёрный — экономит батарею) и Material You (цвета обоев, Android 12+). Идея из клиента ChimeraWire.

Честно: на реальных телефонах и в российских сетях не проверялось — только автотесты и эмулятор.
