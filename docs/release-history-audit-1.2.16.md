# Проверка опубликованной истории — 1.2.16

## Объём и границы
Проверены метаданные всех 145 публичных релизных записей, извлечены все доступные описания (107 с текстом, 38 без текста; 1.2.15 опубликован и добавлен во время проверки). Сверены ключевые исторические утверждения о ядре, однокнопочном подключении, облаке, экономии, отмене проверок и интерфейсе с текущей основной веткой. Повторные теги и экспериментальные ветки не выдаются за 144 уникальные версии одного APK. Для записей без описания функции не угадывались.

Это обзор опубликованных описаний с выборочной проверкой актуального исходного кода, а не сравнение полного исходного diff каждого исторического APK. Удалённые/private/draft релизы публичный API не показывает; не заявляется исчерпывающая история этих записей.

## Не возвращено и не обещается
Большая локальная LLM из 1.0.83 и удалённая модель 1.0.81 не возвращены: 1.0.84 убрал их ради нагрузки/размера. Общий report-token не возвращается. Старые заявления «нулевая задержка», гарантированный обход/охлаждение/ускорение всех сервисов не принимаются за доказанные измерения. Production encryption, ограничения переносимых backup, Android7+ и account/region ограничения остаются явно описанными.

## Проверка
JVM-тесты состояния/геометрии волн, сохранения настроек, дедлайнов/cancellation futures; существующие подключения/облако/security тесты; полная native/Android11+14 проверка в CI перед публикацией. Визуально проверен отдельный HTML-макет палитры и ключевых кадров, не выдаваемый за скриншот Android. Производительность/батарея/внешний вид на физическом телефоне ещё не измерены.
