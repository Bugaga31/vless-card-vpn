# Релиз 1.2.134: заметки о прогонах

- Прогон #232 (release-build-245), e2e (33): упал шаг WARP-пробы. Через WARP прошли 3 из 4 запросов
  (generate_204 — 204, 1 МБ с Cloudflare — 200, YouTube generate_204 — 204); www.google.com ответил 429
  и после штатной 15-секундной паузы — снова 429 (лимит Google на выходной адрес WARP). Тот же шаг в тот же
  час упал и в E2E PR #164. Остальные проверки (e2e 29, masks-matrix) прошли. Код приложения в этом ответе
  не участвует, проверка не ослаблялась; релиз перезапущен этим коммитом.
- Прогон #233: masks-matrix и e2e (29) прошли; e2e (33) — эмулятор Android 13 не загрузился ни с первого
  раза, ни на новом AVD («Timeout waiting for emulator to boot»), до приложения дело не дошло. Перезапуск.
- Прогон #234: masks-matrix прошёл. e2e (29), случай auto: через секунду после подключения эмулятор сменил
  физическую сеть (HANDOFF, новый handle), доказательств для новой сети ещё не было — «Нет рабочего сервера»
  по правилу «без проверки на этой сети не подключаемся». e2e (33), фоновое восстановление: приложение
  восстановилось (check ok=true), но у пробы другого UID один запрос упал на UnknownHostException.
  Тот же код до этого прошёл эти случаи в #232, #233 и E2E PR #164. Перезапуск без изменений в проверках.
