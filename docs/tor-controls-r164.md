# Настройка Tor с главного экрана

## Выбор подключения

В «Как подключаться» есть отдельный выбор Tor. Он использует встроенный Tor и не запускает Fast Auto / поиск VLESS-каталога для подключения. Предыдущий обычный режим сохраняется; выбор «Авто», «Серверы», ByeDPI или «Гибрид» выключает Tor для всего TCP. Сохранённые прямые исключения и выбор приложений не отменяются молча.

«Настроить Tor» открывает мосты, транспорт и ротацию. obfs4 и WebTunnel являются транспортами Tor; произвольная маска VLESS не применяется к ним автоматически. Цепочка Tor поверх VLESS в этой доработке не добавлена. Snowflake/Meek не объявляются встроенными.

## Ротация

Ротация включается отдельно. Интервал задаётся в секундах: 30–86400, по умолчанию 600. Это приблизительный интервал запросов SIGNAL NEWNYM через аутентифицированный ControlPort. Он не гарантирует новый IP, не разрывает существующие TCP-потоки и не заставляет сайты забыть авторизацию/cookies. Энергосбережение, перегрев, пауза и отсутствие сети могут откладывать запрос.

Интервал и порог сохраняются явной кнопкой. Настройки транспорта/ротации применяются при следующем подключении; диалог на главном экране предлагает переподключение.

## Предпочтение быстрых выходов

Настройка использует реальные HTTPS-замеры Cloudflare trace через локальный SOCKS Tor. Из ответа берётся только код страны; IP и содержимое trace не сохраняются. Это задержка запроса с передачей малого ответа, а не Мбит/с и не скорость каждого узла страны.

Порог — 250–15000 мс, по умолчанию 2500. Медленный успешный замер временно исключается из выбора, свежий наиболее быстрый измеренный вариант имеет приоритет без случайного исследования более медленных известных стран. История устаревает через 15 минут и не переносится между физическими сетями. Если свежего подходящего варианта нет, остаётся обычное построение Tor-цепочек, а не ложное подтверждение скорости. Не гарантируются ни самый быстрый узел во всей Tor, ни новый IP.

## Мобильная сеть

Малый пользовательский цикл Tor больше не блокируется только потому, что сеть тарифицируемая. Общие ограничения перегрева, экономии энергии/трафика и выключенного экрана сохраняются. При Wi-Fi↔мобильная сеть используется существующее наблюдение физических сетей, отмена старой работы и переподключение; старый pin страны снимается после аутентификации ControlPort. Ошибка Tor не включает незаметно прямой маршрут вместо Tor. Сохранённые пользовательские прямые исключения остаются исключениями.

Доступность мостов у конкретного оператора, bootstrap и приложения на физическом телефоне должны проверяться отдельно. Unit-тесты и эмулятор не являются такой проверкой.
