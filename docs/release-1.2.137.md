# VLESS Card 1.2.137

Обычный релиз. Пакет com.vlesscardvpn.beta2, versionCode 248; ставится поверх прошлых версий с той же подписью.

## Быстрее после возвращения интернета
- Если приложение ждёт интернет, а Android сообщает, что на **той же сети** он снова подтверждён, проверка VPN запускается раньше, не дожидаясь очередного опроса через 10 секунд. Это помогает после краткого обрыва, например при выходе из лифта или метро. Если Android не прислал такой сигнал, обычный повтор по таймеру остаётся.
- Сигнал Android — только повод проверить связь. Приложение по-прежнему проверяет сам VPN-маршрут и не переключает сервер только из-за уведомления. Прямой обход VPN не добавлен.
- Повторные уведомления и события от неиспользуемой сети не вызывают лишних проверок. При настоящей смене сети работает существующее восстановление; экономия батареи в ручном режиме не меняется.

## Что проверено до публикации
- 2345 debug JVM-тестов и 2344 release JVM-теста (219 наборов), lint release-сборки. Новые тесты проверяют возвращение интернета, повторяющиеся события, другую сеть, пробуждение ожидающего сторожа и сохранение обычного таймера.
- На предыдущем коммите с тем же кодом прошли матрица масок и E2E на эмуляторах API 29 и 33. Итоговый релиз публикуется только после повторных проверок на точном коммите, подписанной сборки и установки/обновления на эмуляторах API 30 и 34.

На настоящем телефоне и в сетях операторов эта версия не проверялась. Буду благодарен за отзыв: как быстро связь возвращается после краткой потери сети.
