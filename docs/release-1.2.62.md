# VLESS Card 1.2.62 — экспериментальный пререлиз

## Изменения

- Для VPN обязателен выбранный удалённый сервер. Отдельный ByeDPI, устаревший гибридный прямой выход и сохранённые публичные direct-исключения больше не заменяют сервер при подключении.
- Tor TCP работает поверх выбранного серверного uplink. UDP остаётся на серверном маршруте: Tor не поддерживает UDP. Локальные uplink-порты доступны только на loopback.
- Auto начинает с ограниченного поиска первого подходящего маршрута; последующая оптимизация не должна необязательно прерывать голосовой сеанс.
- Явный отрицательный результат сервисной проверки исключает маршрут из автоматического пула. UNKNOWN не объявляется PASS.
- Сохранённые предпочтения не стираются: новые ограничения применяются при запуске, что сохраняет возможность отката.
- UDP-проверка получила проверки длины пакетов, запрет перенаправления SOCKS relay за пределы loopback и общий ограниченный deadline.

## Границы проверки

Пререлиз не гарантирует доступность у конкретного оператора. Локальные TLS/SOCKS fixtures проверяют маршрутизацию Xray и отказ обязательного узла; они не доказывают реальный bootstrap Tor или прохождение блокировок. Физический телефон не проверялся. Статус автоматических проверок и SHA кандидата приводятся отдельно в CI.

Android при выключенном VPN может использовать обычную сеть. Это не глобальный killswitch устройства; для него нужна системная настройка «Блокировать соединения без VPN».

Нейромодель не добавлена и не обучалась в этом пререлизе. Стабильный релиз 1.2.61 не заменяется.

## Уточнение E2E после первого CI

Первый CI кандидата 80a6909 завершился с 8 ошибками сценариев на API 29 и 7 на API 33; публикация была остановлена. Установлены несовпадения fixtures: необязательная оптимизация блокировалась действующей power-policy во время тестовой передачи, два сценария ссылались на отсутствующий ID маски, а проверка подбора ждала удалённый standalone-DPI контракт.

Исправлены только E2E fixtures и проверка результатов. Сценарии расширения пула явно разрешают фоновую работу во время тестовой передачи; production power-policy не меняется. Отдельный сценарий Auto chain сохранён. Проверки запуска TPWS/Xray/ByeDPI, полного тела HTTPS от другого UID, аутентифицированного серверного трафика и отказа без сервера остаются обязательными. Новый parser отклоняет частичный, пустой и устаревший результат подбора.
