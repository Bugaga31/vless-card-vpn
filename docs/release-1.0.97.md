# VLESS Card 1.0.97 — сам пересобирает связь за секунды, без «A0 was cancelled»

- Быстрая самопочинка: сторож проверяет связь через VPN каждые 20 с (было 45 с), промах перепроверяется через 3 с. Два промаха подряд (~25 с без ответа) — соединение пересобирается само, как большой кнопкой (секунды). Если за 5 минут это уже было — ищет другие маски и серверы. Нажимать ничего не нужно.
- Больше никаких «A0 was cancelled» и непонятных ошибок: вместо них — «нет ответа (вышло время)», «соединение сброшено (DPI?)», «имя сервера не находится», «прервано — запущено другое действие».
- Диагностика: показывает, если хостинг сервера в открытом списке сетей, где ТСПУ мешает (as-tspu, MIT) — там чаще «заморозка» и тормоза на мобильном.
- Эволюция масок: новый ген «белый SNI» — 18 разрешённых сайтов из открытого списка geosite-cheburnet (MIT); при включённых белых списках пробуется чаще.
- Подписки: добавлены FLAT447 (для мобильного LTE и белые списки lite).

Честно: на реальных телефонах и в российских сетях не проверялось — только автотесты и эмулятор.
