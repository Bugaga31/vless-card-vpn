# Equilibrium 1.2.59 · Bundled AI Preview

Экспериментальное исправление 1.2.58. **Компактная Qwen 0.5B включена в APK**, а не ожидает загрузки с Hugging Face на телефоне. Huihui 27B остаётся отдельной опцией, не выдаётся за встроенную компактную модель.

## Что исправлено

- При первом открытии панели/чата модель потоково копируется из APK в закрытый каталог приложения, сверяется размер и SHA-256. Внешний интернет для этой операции не нужен. Чат включается после подготовки модели; повторно загружать её через прежнюю кнопку не требуется.
- Если написать во время подготовки, вопрос дождётся завершения копирования. Если фоновый нейроплан занял inference, пользовательский вопрос получает приоритет.
- Подготовка файлов больше не блокируется условиями генерации: зарядом, системной экономией или временно занятой ОЗУ. Эти ограничения сохраняются для самой генерации.
- Вместо общего отказа показывается конкретная причина: 32-битный Android, нехватка общей/свободной ОЗУ, низкий заряд, выключенный экран, перегрев, ошибка native runtime или таймаут.
- Постоянный пакет Beta и прежний сертификат сохранены. Настройки и серверы не удаляются. Стабильный Latest не изменяется.

## Как пользоваться

Установите этот APK поверх предыдущей Beta, без удаления приложения. Откройте «Помощник», дождитесь сообщения «Модель установлена из APK», затем пишите вопрос. Отдельная кнопка «Скачать» для компактной модели больше не нужна. После удаления рабочего файла доступна «Подготовить из APK · без интернета».

APK стал примерно на **491 МБ больше**; после установки потребуется ещё около **550 МБ свободного места** для рабочего файла. Неизвлекаемую копию из самого APK можно удалить только вместе с приложением/заменой APK. Кнопка удаления очищает рабочую копию и оперативную историю, не VPN-настройки.

Для inference нужен **64-битный Android**, минимум 3 ГиБ общей и 1200 МиБ свободной ОЗУ. При низком заряде подключите зарядку или зарядите выше 20%; при системной экономии генерация приостанавливается. Не обещаем локальную LLM на всех устройствах. Обычный VPN/Auto от неё не зависит.

В 1.2.58 установлено, что файловая загрузка ошибочно зависела от всех проверок энергоресурсов inference; отдельные внешние сетевые отказы тоже могли мешать. Какая именно причина сработала на телефоне владельца без его диагностики — не установлено. Встроенная модель устраняет внешнюю загрузку из этого пути, но не аппаратные ограничения.

## Минимальные проверки этого пререлиза

По разрешению владельца — только целевые AI unit-тесты, компиляция/сборка, наличие и полный SHA-256 GGUF внутри обоих APK, package/version, постоянный сертификат и подписи v1/v2/v3, отсутствие debug/test CA и E2E hooks. Полная JVM/lint/E2E/эмуляторная матрица не запускается. Стабильные workflow и их gates не ослаблены.

Android inference, установка обновлением и общение на физическом телефоне в этом выпуске не подтверждены. Прежний Linux host smoke runtime не заменяет эти проверки. Это не дообучение на книгах и не гарантия качества ответов 0.5B.
