# VLESS Card 1.2.53 — управление встроенным Tor

## Главное
- Tor добавлен отдельным выбором в «Как подключаться» на главном экране. Для этого подключения не нужен VLESS-сервер и не запускается Fast Auto-поиск каталога.
- На главном экране доступен диалог настройки Tor: мосты, транспорт, ротация и задержка. Прежний обычный режим и пользовательские маски не удаляются.
- Настраиваемый интервал запросов новой цепочки: 30–86400 секунд, по умолчанию 600. Ротация включается отдельным переключателем. Параметры интервала и порога сохраняются явной кнопкой и применяются при подключении.
- Предпочтение быстрых измеренных выходов: свежие HTTPS-замеры через Tor, порог 250–15000 мс (по умолчанию 2500), приоритет наиболее быстрой измеренной страны без случайного исследования более медленных известных вариантов. Это задержка, не скорость скачивания и не гарантия каждого узла страны.
- Малый пользовательский цикл ротации работает и на тарифицируемой мобильной сети, а не блокируется Wi-Fi-only ограничением фонового обслуживания. Перегрев, экономия энергии/трафика и тихий режим по-прежнему могут отложить ротацию.
- При смене физической сети старая работа отменяется; история текущего ротатора начинается заново, прежнее предпочтение страны снимается через аутентифицированный ControlPort.

## Исправления
- Флаг Tor для всего TCP теперь сохраняется и восстанавливается в JSON-профиле.
- Самостоятельный Tor не запускает DPI-движок и фоновые подборы VLESS вместо Tor. Восстановление не включает незаметно прямой основной маршрут.
- Проверка цепочки в настройках обращается к правильному порту ControlPort встроенного Tor.
- Замер задержки использует монотонное время, ответ trace ограничен 8 KiB; IP и тело ответа не сохраняются.
- При ошибке ControlPort повторные запросы ротации ограничены, а закрытый ротатор не продолжает посылать команды.

## Ограничения
- SIGNAL NEWNYM относится к новым соединениям. Он не гарантирует новый IP, не переносит активные TCP-потоки и не меняет cookies/аккаунты сайтов. Интервал приблизительный, не таймер реального времени.
- Известные медленные измерения исключаются временно; если свежих подходящих нет, Tor продолжает обычное построение цепочек. «Самый быстрый узел во всей Tor» не обещается.
- Сохранённые прямые исключения и выбор приложений сохраняются; произвольный UDP через Tor не поддерживается.
- Маскировка Tor настраивается транспортом obfs4/WebTunnel и мостами. Автоматическая цепочка Tor поверх VLESS, Snowflake/Meek и применение произвольной VLESS-маски к Tor не добавлены.
- Нейронка и её исследовательские эксперименты в этот релиз не включены. Облачный каталог, ветка servers и signing workflow не изменялись.
- Автоматические проверки/эмулятор не доказывают работу у конкретного мобильного оператора. Физический телефон, реальные мосты в сети владельца, сообщения Telegram и воспроизведение YouTube должны проверяться отдельно.
