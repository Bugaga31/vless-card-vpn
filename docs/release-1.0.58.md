## Скачайте один файл: **VLESS-Card-Beta-1.0.58.apk**
Ставится **поверх** 1.0.52–1.0.57, настройки сохраняются.

### Своя маскировка «VLESS Card» — теперь 5 стратегий
В режиме «Без сервера» они идут вперемешку с проверенными стратегиями ByeDPI и zapret:
- **Адаптивный каскад** (вторая по счёту). Для каждого сайта сначала самый мягкий обход: обратный порядок пакетов и отдельная TLS-запись по SNI. Если провайдер сбросил соединение, промолчал 3 секунды или испортил TLS, ByeDPI сам повторяет запрос уровнем жёстче (OOB-байт + перестановка в SNI). Если не помогло и это, добавляются поддельные ClientHello. Их SNI каждый раз берётся из списка: ваш домен маскировки, ya.ru, vk.com, gosuslugi.ru, ozon.ru, mail.ru. Рабочий уровень запоминается для каждого IP, поэтому сайты, где обход не нужен, не замедляются.
- **Шредер SNI.** Имя сайта режется на куски по 3 байта, вынесено в отдельную TLS-запись, а первый байт уходит последним.
- **Сплит SNI → маскировка** (из 1.0.57).
- **Шредер хоста (zapret).** TLS-запись режется внутри SNI, плюс разрезы на всех границах домена в обратном порядке.
- **Другая версия TLS-записи.** Заголовок записи помечается версией 0x0304. По стандарту TLS 1.3 сервер обязан игнорировать это поле, а простые DPI-сигнатуры «16 03 01» перестают совпадать.

У адаптивных стратегий первое соединение может уйти на «распознавание» DPI. Поэтому, если первая проверка не прошла, приложение проверяет их ещё раз и только потом переходит к следующей. Общий лимит подбора вырос до 2,5 минуты, всего стратегий 20.

### Проверено
- На компьютере: все новые стратегии собранным из исходников ByeDPI/zapret передают HTTPS (по 3 из 3 запросов).
- Эмулятор Android: встроенные бинарники с аргументами приложения передают ClientHello без порчи. Полный TUN «другое приложение → VPN → каскад → HTTPS + DNS», 2 цикла запуска.
- Не проверено: реальная сеть Билайн и то, что каскад действительно переключает уровни на настоящем DPI. В тестах DPI нет, поэтому срабатывает только первый уровень.
