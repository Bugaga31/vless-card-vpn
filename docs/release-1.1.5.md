# VLESS Card 1.1.5

**Обновления прямо в приложении.** Больше не нужно ходить на GitHub: приложение само проверяет новые версии (раз в 6 часов), на главной появляется «Доступна версия … — Обновить». Нажали — скачивается файл именно для вашего телефона и открывается окно Android «Установить?» (без подтверждения Android ставить не даёт ни одному приложению). Первый раз Android попросит разрешить VLESS Card устанавливать обновления. Вручную: Настройки → «Обновление». Это обновление ещё ставится по-старому, следующие — из приложения.

**Облачная проверка серверов.** Каждые 6 часов GitHub сам собирает все подписки из каталога и большие мировые сборники (десятки тысяч серверов), убирает повторы, пингует каждый со своих машин и публикует ответившие, быстрые первыми. Приложение получает этот список как подписку «VLESS Card · облачная проверка» (для России включена сама, мировая на 6000 — в «Подписках»). Мёртвые серверы отсеиваются ещё до телефона — проверка на телефоне быстрее. Честно: машины GitHub за границей, поэтому облако отсеивает выключенные серверы, а проходит ли сервер блокировки у вашего оператора — по-прежнему решает проверка на телефоне.

**Мини-нейросеть учится лучше.**
- Учится не только на проверках, но и на реальной работе: интернет через выбранные серверы пошёл — плюс им, связь оборвалась — минус.
- Учитывает время суток (вечером операторы режут сильнее).
- Сначала учится быстро, потом спокойнее — одна странная проверка не перечёркивает сотни хороших.
