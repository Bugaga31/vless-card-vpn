## Адаптация к новой сети и первое приветствие

- Смена Wi-Fi → Wi-Fi, Wi-Fi → мобильная сеть и изменение сетевого профиля теперь запускают отдельную отложенную перепроверку физических сетей, а не только VPN-сети Android. Повторяющиеся события объединяются; устаревшие проверки отменяются.
- Локальная онлайн-модель рейтинга хранит отдельные веса для сетевых профилей (до 24). Результат старой сети не должен обучать новую. Это небольшая логистическая модель, не нейросеть для управления чужими приложениями; модуль диагностики телефона остаётся отдельным.
- При переходе в новую сеть Авто сравнивает до восьми кандидатов из локальной памяти, облачных подсказок и разных узлов. Затем последовательно проверяет загрузку у трёх финалистов в ограниченном бюджете. Облако даёт кандидатов, но победителя подтверждает телефон.
- Выученная маскировка другой сети не переносится вслепую: известные сетевые маски сохраняются для возвращения; в неизвестном профиле начинается базовая проверка. Ручная глобальная маска не сбрасывается.
- Если Android скрывает SSID, используется локальный солёный идентификатор текущей сессии Wi-Fi. Это отличает сети даже с одинаковым адресом роутера, но после повторного подключения может потребоваться новое обучение. Новые разрешения геолокации не запрашиваются, сведения о сети не отправляются в облако.
- Короткий мягкий дзинь при открытии. Английское «Thank you for installing me.» — только при первом запуске этой установки, с установленным офлайн-голосом English. Отметка сохраняется при обновлении и перезапуске; после очистки данных/переустановки приветствие снова считается первым. Тихий первый запуск тоже погашает голосовое приветствие, чтобы оно не звучало неожиданно позже. Для уже установивших приложение до этой версии первый запуск 1.2.25 создаёт отметку.
- Звук можно выключить в настройках; беззвучный режим, «Не беспокоить», звонок и играющая музыка учитываются. Громкость системы не меняется, голос не скачивается.

Переподключение сохраняет интерфейс VPN при возможности; существующие TCP-сессии могут перезапуститься. Мгновенное или бесшовное переключение на любой сети не гарантируется. Реальное переключение между двумя роутерами и наличие английского TTS на конкретном телефоне требуют проверки на устройстве.
