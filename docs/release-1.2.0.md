# VLESS Card 1.2.0

- **Облако теперь действительно работает каждые 10 минут.** Расписание GitHub (cron) у этого репозитория не срабатывало ни разу, поэтому облако запускает себя само: проверка → публикация → через 10 минут следующая.
- **Облако проверяет серверы по-настоящему, а не только пингом.** Около 2500 лучших серверов получают настоящий HTTPS-запрос через Xray-core. Те, что реально пропустили трафик, стоят первыми в «облачной проверке» (самые быстрые — в начале). Серверы, которые только отвечают на пинг, но ничего не пропускают, уходят в конец. Отдельные списки works_ru.txt / works.txt — только рабочие.
- **Облако учится:** оно помнит каждый сервер между запусками (сколько раз сработал, средняя скорость; старое постепенно забывается). Стабильные серверы идут первыми, умершие быстро уходят вниз, а ранее рабочие проверяются в каждом запуске.
- **Облако быстрее:** подписки качаются параллельно, пинг — 2000 соединений одновременно с короткими тайм-аутами, реальная проверка — по 400 серверов в одном Xray, 192 запроса одновременно.
- **ByeDPI и zapret поднимаются сами.** Если движок обхода упал во время работы VPN, он за 2 секунды перезапускается на том же порту — без переподключения и без «пропал интернет».
- Автопроверки сборки исправлены: подбор обхода DPI проверяется по новому итогу (YouTube открыли N из M), матрица масок не считает маски, которые приложение не предлагает для WebSocket, а тестовый ByeDPI перезапускается после падения.

Важно: версии 1.1.x не видят 1.2.0 через встроенное обновление (они знают только номера 1.0/1.1) — один раз поставьте APK вручную, дальше обновления снова приходят сами.
