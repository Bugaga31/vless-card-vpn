# VLESS Card 1.2.51

Исправления запуска Tor и более строгие проверки выпуска. Это не обещание
мгновенного подключения или работы у любого оператора.

## Tor
- Демон запускается до проверки подключения, в том числе в режиме «весь трафик через Tor»,
  а не только после успешного интернет-теста, который сам мог зависеть от Tor.
- Создание control-cookie и готовность ControlPort ожидаются ограниченное время.
  Сетевые операции ротатора вынесены с основного потока.
- Задача ротатора отменяется при смене сети и переподключении; собственный демон
  останавливается при полном отключении. После закрытия/неудачного переподключения
  ротатор не использует старое состояние «подключён».
- Встроенные транспорты: обычный Tor, obfs4, WebTunnel. Неподдерживаемый транспорт,
  в том числе сохранённый Snowflake, не должен молча становиться обычным Tor:
  нужно выбрать поддерживаемый режим. Snowflake/Meek в APK этим выпуском не добавлены.
- Страны не угадываются по именам VLESS-серверов. Некорректные измерения не участвуют
  в ранжировании. Добавлена защита от управляющих строк в torrc/ControlPort.

## Совместимость Android
- Исправлены найденные release-lint ошибки API-веток Android 7/8/10,
  подписки Compose на изменяемое состояние и константы mock-location.
- Нативный DPI/Tor требуют Android 8+; старый Android не должен вызывать
  недоступные методы. Внешний вид Ocean Signal не перерабатывался.

## Проверки выпуска
- Публикация зависит от E2E API 29/33 и masks matrix на том же SHA.
- JVM-тесты, release lint, обе подписи APK, package/version и отсутствие целевых
  debug/fixture-маркеров проверяются с явным отказом при нарушении.
- Сертификат должен совпадать с опубликованной 1.2.50.
- Встроенный Android Tor запускается с --version и проверяет точные сгенерированные
  конфигурации без сети (--verify-config, DisableNetwork); это не bootstrap-тест.
- Проверяется установка подписанного APK поверх 1.2.50 на API 30/34;
  это не доказательство сохранности данных настоящего пользователя.
- CI-действия в затронутых workflow закреплены полными SHA; ключ удаляется через trap.
- verification.json содержит SHA исходников, результаты и хеши APK.

## Ограничения
- Встроенный Tor работает от UID приложения. Цепочка «Tor поверх VLESS» не считается
  реализованной или доказанной этим выпуском. Tor не поддерживает произвольный UDP;
  работа Discord-голоса через Tor не обещается.
- Реальный bootstrap Tor и доступность конкретных мостов в сети владельца,
  Telegram, воспроизведение YouTube, физический телефон и российский оператор
  не проверяются одними JVM-тестами/эмуляторными установками.
- HTTPS-ответ сайта не заменяет MTProto или передачу видео; UNKNOWN не является PASS.
- Изменения не добавляют лабораторию, обучение, сканирование endpoints или облачный каталог.
