## Какой файл скачать
- **VLESS-Card-Beta-1.0.68-arm64.apk** — для почти всех телефонов (64-битных).
- **VLESS-Card-Beta-1.0.68.apk** — универсальный, если arm64-файл не ставится.

Ставится **поверх** 1.0.67, настройки и серверы сохраняются.

### Умный подбор обхода DPI
- **Финал по-настоящему**: раньше побеждала первая стратегия, открывшая страницу YouTube. Теперь 8 самых быстрых проходят две проверки на трёх целях: страница YouTube, видео-CDN YouTube (картинки и превью, их режут как видео) и Discord. Побеждает та, что открывает больше всего и стабильно, а уже потом — быстрее. Рядом со стратегией видно, сколько проверок она прошла, например «✓ 6/6».
- **Эволюция стратегий** (только в VLESS Card): у трёх лучших стратегий ByeDPI появляются «мутанты» — другие места разреза и перестановки, другой TTL фейка, добавленное разбиение TLS-записи. Они соревнуются в финале наравне со встроенными. Если побеждает выведенная стратегия, приложение так и пишет: такой нет ни в одном списке, и ТСПУ её не знает.
- **Запасные стратегии**: для каждой сети запоминаются 5 лучших. Если выбранную распознали, приложение мгновенно переключается на следующую, без нового долгого поиска. После нескольких неудач оно само запускает новый подбор.
- В режиме «ByeDPI» тоже работает самовосстановление: сторож связи замечает обрыв и сам меняет стратегию.

### Меньше падений
- Ошибка в фоновой задаче (проверка, восстановление, ускорение, сохранение) больше не роняет приложение.
- Если в «Авто» VPN не запустился, приложение не сдаётся. Сначала пробует без маскировок, потом — через обход DPI без сервера.
- Отключение VPN больше не может подвесить приложение («Приложение не отвечает»), даже если в этот момент идёт поиск.
- Если не удалось сохранить данные (например, кончилось место), приложение не падает, а повторит сохранение позже.
