# VLESS Card 1.2.97 Experimental

## Исправления Telegram
- Фоновые результаты Telegram и DNS теперь обновляют карточку сервисов, а не остаются только во внутреннем состоянии.
- Свежий сбой/неопределённый результат заменяет старое зелёное подтверждение. Отдельная свежесть по каждому модулю: HTTPS не продлевает жизнь старому результату YouTube/DNS.
- Дополнительная защита от публикации результатов предыдущей цепочки.
- Ответ тестового DC подписан как ответ дата-центра, а не гарантия работы приложения.

## Tor и обязательные мосты
- Автонастройка и запуск Tor требуют obfs4/WebTunnel; старый режим «без мостов» обновляется до obfs4. Валидные сохранённые/ручные мосты не удаляются.
- Источник по умолчанию — igareck TOP100 (raw.githack.com), ограниченное обновление раз в 6 часов; при ошибке сохраняется прежний список, явное отключение автообновления соблюдается. Источник видит запрос списка.
- Нет запуска без мостов и нет прямого fallback. Для подтверждения нужна управляемая встроенная Tor-цепочка; чужой локальный Tor не принимается как доказательство.
- Пока Tor строит цепочку, Telegram не показывается подтверждённым. Задержка построения цепочки сама по себе не объявляет VLESS нерабочим. Готовность перепроверяется.

## Границы этого исправления
Это исправление ложных/устаревших статусов и старта Tor, не обещание исправить любой сбой Telegram. Пробы локальные SOCKS; полный путь приложения через TUN, аккаунт, конкретный DC/медиа и реальные звонки не подтверждены. Первая Tor-цепочка не обязана строиться мгновенно.

Выбор произвольного набора проверок сервисов и отдельное сравнительное ранжирование VLESS-резервов именно под Tor в этот hotfix НЕ включены. Никакой готовности этих функций не заявляется.

Main/latest не изменяются. Только экспериментальный prerelease; постоянная подпись Beta.
