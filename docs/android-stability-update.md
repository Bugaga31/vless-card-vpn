# Исправления стабильности и стабильный TLS

## Область изменения

Этот патч сохраняет sing-box/libbox. Он не заменяет ядро на V2Ray/Xray и не встраивает Tor/Orbot. Без crash log с конкретного устройства нельзя установить точную причину исходного вылета.

### Запуск и остановка

- Нативная библиотека больше не загружается из `Application.onCreate`. `Seq.setContext` и `Libbox.setup` выполняются в IO-корутине VPN-службы после успешного `startForeground`.
- Ошибка foreground-перехода прекращает подключение: тяжёлая инициализация не продолжается.
- Перед запуском проверяется не только структура JSON, но и конфигурация через `Libbox.checkConfig`.
- CommandServer сохраняется до `start/startOrReloadService`, чтобы его можно было закрыть при частичном сбое. `closeService` и `close` вызываются независимо.
- Очистка при уничтожении службы сериализована с запуском ядра, чтобы не закрывать JNI-объект одновременно с запуском.
- Запрос VPN-разрешения происходит только для подготовленного подключения. Убраны пересекающиеся запросы при старте экрана.
- Фоновые ошибки UI/службы сохраняются в локальных отчётах. JVM `catch` **не перехватывает** SIGSEGV/SIGABRT в нативном коде; для таких случаев нужен Android logcat/tombstone.
- Base64-парсер использует Android-декодер на API 24/25, где `java.util.Base64` ещё нет. Убрано чтение поколения мобильной сети без READ_PHONE_STATE; новый атрибут темы вынесен в values-v27.
- Для Quick Settings на Android 14 используется `startActivityAndCollapse(PendingIntent)` вместо неподдерживаемого Intent-варианта.

### Публичные подписки

Ограничены размер ответа (2 MiB), число кандидатов (500) и список источников (24). Запросы имеют общий таймаут 12 секунд, HTTPS→HTTP перенаправления отключены. Отмена не поглощается как обычная ошибка. Проверка доступности узла сама по себе не доказывает работоспособность VPN-аутентификации или обход блокировок. Публичные серверы принадлежат сторонним операторам; для чувствительных данных предпочтителен доверенный сервер.

### Профиль «Стабильный TLS»

Кнопка на главном экране сохраняет `evasionStrategy=stable_tls`, отключает случайную ротацию SNI и экспериментальную фрагментацию, сбрасывает пользовательскую подмену SNI на `auto`.

- SNI, fingerprint, REALITY public key/short ID и Vision flow сохраняются из конфигурации сервера.
- Проверка TLS-сертификата не отключается.
- При отсутствии SNI обычный TLS использует адрес сервера, а REALITY требует явно заданное имя или осознанный пользовательский override. Подмена доменом оператора или случайным доменом не используется.
- Это совместимый профиль существующих технологий, а не новый протокол, «невидимость» или гарантированный обход DPI.
- Профиль применяется при следующем подключении. Уже запущенная сессия автоматически не прерывается.

### Интерфейс

Главный экран заменён статичной панелью с контрастной синей темой, основной кнопкой подключения/отмены, карточкой сервера, двумя читаемыми метриками, TLS-профилем и диагностикой. Убрана постоянная пульсирующая анимация. Сообщения показывают фактическое состояние ядра без заявления, что все сайты доступны или весь трафик защищён. Общие токены темы обновляют цвета остальных экранов.

## Проверка на телефоне

1. Экспортировать пользовательские конфигурации перед заменой установленного APK. Для обновления без переустановки нужна та же подпись, что у установленной версии; локальный debug APK может иметь другую подпись.
2. Открыть приложение без сети: главный экран должен открыться без загрузки native core и без автоматического системного VPN-диалога.
3. Подключить известный доверенный сервер; разрешить VPN; проверить, что foreground-уведомление появилось.
4. Повторить подключение/отключение, поворот экрана, запуск из VPN-плитки, отзыв VPN-разрешения и переключение Wi-Fi/мобильной сети.
5. Применить «Стабильный TLS», переподключиться, проверить доступность сайтов через диагностику.
6. Проверить Android font scale 1.0 и 1.3 на узком экране, ERROR/CONNECTING/DISCONNECTED состояния и длинные имена серверов.
7. При вылете приложить модель устройства, Android, версию APK и лог из Настройки → Отчёты об ошибках. Для нативного падения получить logcat; не публиковать URI, пароли или ключи.

## Команды сборки

```bash
./gradlew :app:assembleDebug :app:lintDebug
```

`assembleDebug` зависит от `testDebugUnitTest`. Новые regression-тесты проверяют сохранение SNI/Reality/Vision, отсутствие экспериментальной фрагментации в стабильном профиле и ограничения размера подписок.
