# 1.2.37 · запасной источник медиапроверки

Основа — опубликованная 1.2.36. Сохранены её фоновый обход каталога, ограничение нагрузки, защита смены сети, раздельные результаты HTTPS/Telegram/YouTube и постоянный ключ обновления.

- Если контрольная watch-страница YouTube не предоставляет прямой адрес видео, проверка пробует анонимный player API через ту же SOCKS-цепочку и в пределах того же общего дедлайна. Успешная watch-страница не вызывает дополнительного API-запроса.
- Ответ API ограничен 1 МиБ при чтении. Допускается только HTTPS-видео с разрешённого googlevideo-хоста; аудио, HTML, подпись без прямого URL и ошибка ресурса не становятся подтверждением. Для PASS по-прежнему требуется фактическая загрузка 128 КиБ видео.
- Неудачный fallback сохраняет исходную причину отсутствия подтверждения. Отмена не запускает запасной запрос; новые независимые окна ожидания не добавлены.
- Telegram может попробовать дополнительные официальные DC после быстрых отказов первых адресов. Общий бюджет 8 с и до 4 с на отдельный медленный SOCKS/MTProto handshake сохранены: расширение списка не обрезает рабочие медленные подключения.
- Исправлены вызовы API процессов, MTU и планировщика обновлений для Android 7–9; избранное в меню сервера наблюдает состояние Compose. Полный release lint теперь обязателен в workflow выпуска.
- Стенд обхода 16 конфигураций явно разрешает фоновую работу при активном трафике: иначе системная/тестовая передача на эмуляторе могла законно отложить проверку и сорвать 300-секундное ожидание. Только этот сценарий меняет настройку; в приложении защита включена по умолчанию, её регрессионные тесты сохранены. Требование 8 реальных результатов вне пула не ослаблено.
- Отложенный из-за активного трафика выбор серверов повторно применяется к работающему Xray и в режимах Servers/Hybrid, а не только Auto. Пустой выбор и режим без сервера не создают цикл переподключений. E2E требует фактический пул из трёх живых серверов после удаления четвёртого нерабочего, а не гоняющийся с автоматическим таймером Boolean одного вызова.
- Добавлены регрессии fallback, ограничения размера, отсутствия ложного PASS, отмены и дополнительных DC. Подпись, запуск на Android, проверки Xray и masks/WARP остаются обязательными условиями публикации.

Доступность публичных сервисов зависит от сети и серверов. Эти изменения не гарантируют ускорение любого телефона или работу YouTube/Telegram у всех операторов. Локальный стенд не заменяет проверку на реальном устройстве.
