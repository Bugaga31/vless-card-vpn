# Продолжающийся поиск Auto

Кнопка Auto больше не завершает поиск только потому, что первые восемь кандидатов не дали рабочую цепочку.

- Одна сессия использует снимок уже имеющегося допустимого каталога. Новые подписки и случайные адреса не сканируются.
- Проверки идут партиями до восьми конфигураций, до четырёх маршрутов одновременно. Партии используют один монотонный срок: максимум 120 секунд вместе с запуском конечной цепочки. Таймер между партиями не обнуляется.
- Внутри партии сначала проверяются две волны передачи данных; сервисная проверка первой волны не должна лишать вторую времени на HTTPS.
- Подтверждённые Telegram и YouTube имеют приоритет. Data-proven UNKNOWN сохраняется как предварительный fallback до исчерпания доступных вариантов или резерва времени. Явный сервисный FAIL исключает маршрут.
- Результат предварительной проверки не считается подключением. Запущенная цепочка обязана передать реальные HTTPS-тела с двух независимых узлов. При её отказе сессия исключает выбранный пул и продолжает доступные варианты без повторного подключения этого пула.
- Три независимых HTTPS-контроля запускаются параллельно через тот же SOCKS-клиент. Зависший контрольный ресурс не отнимает у двух остальных весь срок. Размер — до 64 КиБ на ресурс; код 204, HTML, один узел и неполное тело не подтверждают передачу.
- Оставшиеся HTTP-вызовы отменяются при успехе, сроке и отмене. Поздние ответы не меняют выданный результат. Частный HTTP executor освобождается после проверки.
- После запуска VPN проверки MTProto и YouTube-медиа начинаются немедленно, отдельно от HTTPS. Надпись «работает» относится только к свежему PASS соответствующей проверки; UNKNOWN и устаревший результат не превращаются в PASS.
- Смена сети, отмена и новая генерация запрещают подключение по старым результатам.

Это сознательное изменение прежнего контракта кнопки «15 секунд / первые восемь». Старый ограниченный Fast Auto helper сохраняет 15-секундный предел; продолжающаяся сессия явно сообщает пользователю предел в две минуты. Бесконечного цикла нет. Исчерпание каталога или времени не является доказательством отказа всех неизвестных маршрутов.

Репозиторий tor-rotator-vless изучен только как пример перехода к следующей цепочке. Его код, зависимости и упрощённая проверка Tor не переносились. Сетевые проверки не гарантируют доступность у конкретного оператора; эмуляторные fixtures не являются проверкой реальных Telegram и YouTube на телефоне.

Публикация, подпись, версия, release workflow, облачный каталог, формат обучения и лаборатория данным изменением не затрагиваются.
