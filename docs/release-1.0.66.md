## Какой файл скачать
- **VLESS-Card-Beta-1.0.66-arm64.apk** — для почти всех телефонов (64-битных, примерно с 2017 года). Весит примерно вдвое меньше.
- **VLESS-Card-Beta-1.0.66.apk** — универсальный, если arm64-файл не ставится («Приложение несовместимо»).

Оба ставятся **поверх** 1.0.65, настройки и серверы сохраняются.

### Ключи WARP+: выбрать и включить
- Настройки → WARP → **«Ключи WARP+: выбрать и включить»**: все ключи (свои и 135 встроенных) списком.
- У каждого ключа видно, что ответил Cloudflare: работает, занят («слишком много устройств») или недействителен.
- Галочка решает, участвует ли ключ в автонастройке. Кнопка **«Подключить»** настраивает WARP именно с этим ключом.
- Приложение запоминает ответы: рабочие ключи пробуются первыми, занятые — последними (через 3 дня им даётся новый шанс), недействительные больше не пробуются.

### Мои маскировки
- Настройки → **«Мои маскировки»**: соберите свою маскировку — дробление, лесенку, UDP-шум (можно свой JSON), смену порта для WireGuard/WARP.
- **Поделиться**: маскировка превращается в ссылку `vcmask://…`, её можно отправить в чат. В ссылке только параметры маскировки, без серверов и ключей.
- Чужую ссылку можно вставить кнопкой «Вставить ссылку» или в «Добавить» на вкладке «Серверы».
- Долгое нажатие на сервер → **«Сделать свою на основе текущей»**: берёт маскировку, которая сейчас работает, за основу.
- Свои маскировки пробуются первыми при подборе.

### Больше маскировок: 440 вместо 378
- Новые лесенки: «вниз 60→20→5→1», «рваный ритм», «SNI по 1 байту с паузами» и дробление первых 1-4 пакетов.
- WireGuard/WARP: «AmneziaWG: 1 большой + 6 мелких» и «QUIC + мусор AmneziaWG», в том числе с прыжками по портам.

### Ускорение стало умнее
- Первая фоновая проверка — через 2 минуты после подключения. Если сервер сменился, следующая будет через 5 минут, а пока всё стабильно, интервал растёт до 30 минут, чтобы беречь батарею.
- При смене сети (Wi-Fi ↔ мобильный) поиск сервера быстрее запускается через 45 секунд.
- На Wi-Fi учитывается не только пинг: если текущий сервер рвёт большие загрузки (видео подвисает), а другой их держит, приложение переключится.

### Приложение стало легче
- Включено сжатие кода (R8): раньше код весил около 32 МБ, теперь около 2,5 МБ.
- Отдельный APK под arm64: в нём нет библиотек для 32-битных телефонов.

### Публичные серверы помечены
- У серверов из встроенного каталога подписок в списке есть пометка «публичный». Такие серверы держат посторонние люди, поэтому вход в банк и важные аккаунты лучше делать через свои серверы.
