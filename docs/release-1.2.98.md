# VLESS Card 1.2.98 Experimental — выбираемые проверки Авто

**Где:** Настройки ⚙ → Автоматический выбор → Что проверять в Авто. Изменения сохраняются сразу, без принудительного разрыва текущего подключения.

- HTTPS обязателен. Отдельно включаются Telegram (ответ дата-центра), устойчивость Telegram, UDP-транспорт для звонков, Discord gateway и YouTube-медиа.
- По умолчанию включены Telegram, устойчивость, UDP и Discord; YouTube выключен. Устойчивость включает необходимые пробы Telegram.
- Выбранные проверки участвуют в допуске кандидатов и резервов. Подтверждение для старого набора проверок или другого допуска задержки не переиспользуется; требуется свежая проверка.
- Если проверки неизвестны или не завершены, интерфейс не показывает старое подтверждение как текущий успех.
- Для Tor отключите UDP-проверку: Tor не передаёт UDP. Обязательные мосты и проверки готовности Tor из предыдущей версии сохранены.

**Ограничения:** ответ Telegram DC не подтверждает работу аккаунта, приложения или звонка. Discord gateway не проверяет авторизацию или голосовую сессию. UDP/STUN — синтетическая транспортная диагностика, не настоящий звонок Telegram/Discord. Не проводились испытания полного TUN-пути, реального оператора/DPI и физического устройства. Мгновенное подключение, скрытие зарубежного IP от провайдера и восстановление за секунду не гарантируются.

Только экспериментальный пререлиз; main/latest не меняются. Проверки, подпись и контрольные суммы — в приложенных отчётах.
