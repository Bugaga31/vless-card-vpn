# VLESS Card 1.0.84 — без нейросетей; помощник сам управляет масками и настройками; пинг в разы быстрее

## Убрано
- **Нейросеть масок** (1.0.81) и **ИИ-модель в помощнике** (1.0.83, DeepSeek / Qwen) удалены полностью, вместе с движком: приложение снова меньше на ~12 МБ.
- Если модель была скачана, при первом запуске она удаляется сама, и место (0,5–1,8 ГБ) освобождается. Файл обучения нейросети тоже удаляется.
- Подбор масок работает как до 1.0.81: сначала маски, которые уже проходили в этой сети, потом лёгкие, потом остальные.

## Помощник управляет приложением
Остался прежний помощник с ответами по шаблонам. Теперь он **выполняет команды** сразу, результат приходит в чат:
- **«Ускорь YouTube»**: включает «Умный YouTube» и ускорение телефона, заменяет тяжёлые маски лёгкими, меряет реальную скорость лучших серверов, выбирает самые быстрые и заново решает, пускать ли YouTube через обход DPI. Если VPN подключён — переподключается.
- **«Облегчи маску»** — заменяет тяжёлые маски лёгкими там, где они проходят.
- **«Смени маску»** — переключает на следующую проверенную маску.
- **«Включи авто»**, **«Подключи / отключи VPN»**.
- **«Включи / выключи турбо»**, **«Блокируй рекламу»**, **«Выключи QUIC»**.
- **«Что режут в моей сети?»** и **«Какие маски лучше?»** — ответы строятся по статистике проверок масок в этой сети, без нейросети. Например: «Помогает: дробление TLS hello (+60%). Мешает: один поток (mux) (−40%)», «прошла 4 из 4».

## Помощник знает телефон
**«Что с телефоном?»**: модель, Android, ядра, память, свободное место, батарея, энергосбережение, сеть и её оценка скорости, частный DNS, экономия трафика. Помощник прямо пишет, что из этого мешает VPN:
- оптимизация батареи (есть кнопка «Разрешить работу в фоне»);
- энергосбережение;
- частный DNS;
- мало памяти;
- низкий заряд.

## Пинг в разы быстрее
- Раньше TCP-пинг упирался в пул из 96 потоков: 1000 серверов проверялись пачками по 96, и каждый мёртвый сервер держал поток до 2,5 с.
- Теперь все серверы пингуются разом неблокирующими сокетами в одном потоке (до 512 соединений одновременно). Имена серверов разрешаются параллельно, каждое по одному разу. Результаты появляются по мере прихода.
- В тесте: 300 адресов, из них треть мёртвых, — меньше 3 секунд вместе с ожиданием мёртвых.

## Честно
На реальных телефонах не проверялось: сборка и 64 юнит-теста (пинг на 300 адресах, команды помощника, ответы по статистике, данные телефона).
