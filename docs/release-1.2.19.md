# 1.2.19 — ограниченное сравнение финалистов

- В начальной короткой HTTPS-волне проверяются до четырёх разных маршрутов вместо двух. Затем сравниваются до трёх финалистов: измеренный лидер, кандидат для перепроверки и ещё один маршрут, с предпочтением разных хостов.
- Скорость лидера старше пяти минут перепроверяется при следующем Авто, если позволяют заряд, температура и текущая нагрузка. Свежие замеры повторно не скачиваются без необходимости.
- Если короткая перепроверка не подтвердила прежнюю скорость, старое значение не даёт кандидату преимущество в этой гонке. История сохраняется без ложного штрафа за таймаут.
- Загрузки выполняются последовательно, без конкуренции друг с другом. Общий бюджет этапа сравнения — 7 секунд, включая ожидание ядра/мьютекса и запуск; на одну пробу — не более 2,5 секунды, остаток менее 0,8 секунды не используется. Короткий таймаут не записывается как подтверждённый отказ.
- При активном трафике, перегреве, экономии энергии или игровой сессии дополнительные скачивания откладываются. В игровом режиме выбор идёт по задержке/стабильности, а не по пропускной способности.
- Результаты, завершившиеся после смены базовой сети, не обучают старый профиль. Устаревший callback не запускает подключение на новой сети; требуется повторное Авто.

Это короткая оценка небольшой группы кандидатов, не измерение максимальной скорости всех серверов и не гарантия доступности каждого сервиса. Общий бюджет относится к этапу сравнения скачивания, а не к подпискам, обходу DPI или всему подключению. Устройства ниже Android 7 по-прежнему не поддерживаются.
