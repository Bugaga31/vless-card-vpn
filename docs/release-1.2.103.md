## Изменения

- В Авто выбранные Telegram/YouTube больше не показываются как «Не требуется» из старого отключённого замера: требуется новый результат. Неизвестный результат не считается успешным.
- Для сервисных задач каждого кандидата выделены отдельные ограниченные рабочие потоки: загрузка медиа у других кандидатов не занимает всю общую очередь. Таймаут/отмена/ошибка различаются в причинах отказа.
- Кнопка найденных на главном экране доступна и для Tor: выбирает проверенный VLESS-вход, после чего требуется построение Tor через сохранённые obfs4/WebTunnel-мосты. Это не подтверждение готового Tor-выхода. UDP через Tor недоступен; выбранную UDP-проверку нужно отключить вручную.

## Ограничения

Сбой пользователя на реальном телефоне не воспроизведён. Тест очереди — локальная многопоточная фикстура, не измерение сети/нагрева. Полный TUN, реальные аккаунты/звонки, Android UI, скорость на провайдере не проверены. Установка поверх прежней Beta2 без удаления данных; подпись должна совпадать.
