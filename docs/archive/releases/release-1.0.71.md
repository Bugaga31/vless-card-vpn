## Какой файл скачать
- **VLESS-Card-Beta-1.0.71-arm64.apk** — для почти всех телефонов (64-битных).
- **VLESS-Card-Beta-1.0.71.apk** — универсальный, если arm64-файл не ставится.

Ставится **поверх** 1.0.70, настройки и серверы сохраняются.

### Вся маскировка включается сама
При обновлении (и сразу на новой установке) один раз включается всё:
- скрытый локальный прокси;
- блок QUIC — браузеры и YouTube идут через маскируемый TCP+TLS;
- смена маскировки при каждом подключении;
- эволюция масок и самовосстановление;
- российские приложения мимо VPN, случайный адрес VPN, фон обычного пользователя;
- если вы ограничивали семейства масок — к ним добавлены «Фирменные VLESS Card» и «Авто-маски».

Дальше ваш выбор сохраняется: если что-то выключите, оно останется выключенным.

### Ещё 15 фирменных маскировок (всего фирменных — 33, всех — 518)
- **Быстрый старт (TCP Fast Open)**: данные уходят уже в первом пакете соединения. DPI, который ждёт обычного рукопожатия, видит непривычное начало. Если сеть не поддерживает — само откатывается.
- **Путь через IPv6**: если у сервера есть IPv6-адрес, соединение идёт сначала по нему (у многих провайдеров IPv6 фильтруется слабее), IPv4 — запасной в гонке.
- **Белый SNI + MSS 120** для vk.com, ya.ru, gosuslugi.ru, ozon.ru.
- **ALPN браузера + дробление**, **iPhone + ALPN браузера**.
- **Один поток + рваный ритм**, **один поток через обход DPI**.
- **«Невидимка-6»** (IPv6 + Safari + ALPN браузера + узкий канал + один поток) и **«Невидимка-турбо»** (быстрый старт + MSS 120 + один поток).
- Эволюция масок теперь скрещивает и быстрый старт, и IPv6.
- Новые фирменные — в самом начале подбора.
