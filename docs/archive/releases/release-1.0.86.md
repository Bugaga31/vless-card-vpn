# VLESS Card 1.0.86 — подстройка под приложение и GPS

- «Под приложение» (вкл. по умолчанию): видит, какое приложение открыто. Gemini, ChatGPT, Claude, Copilot, Perplexity, Spotify, Netflix — если текущие серверы в стране, где сервис не работает (или страна неизвестна), сам переключает на серверы США/Нидерландов/Германии… без разрыва VPN. YouTube — один раз на сеть запускает «Ускорить YouTube». Нужен «Доступ к истории использования» (кнопка в Настройках).
- «GPS под страну сервера» (выкл. по умолчанию): пока VPN включён, телефон «находится» в столице страны сервера. Нужно выбрать VLESS Card в Параметрах разработчика → «Приложение для фиктивных местоположений». После отключения VPN возвращается настоящее местоположение.
- Помощник: «включи GPS», «выключи GPS», «подстраивайся под приложения», подсказки и кнопки для разрешений.
- «Автопилот помощника» (вкл. по умолчанию): пока VPN включён, помощник сам следит за связью — пропал интернет 2 проверки подряд → «Починить» (не чаще раза в 3 мин), тяжёлая маска → ищет лёгкую (раз в час). Пишет о действиях в чат и на главную.
- Помощник понимает «улучши соединение», «включи/выключи автопилот».
