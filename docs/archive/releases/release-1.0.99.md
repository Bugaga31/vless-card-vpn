# VLESS Card 1.0.99 — ещё быстрее

- Прогрев: сразу после подключения приложение заранее узнаёт через VPN адреса YouTube (и его видеосерверов), Google, Telegram, Instagram, Discord, ChatGPT, X — первое открытие не ждёт DNS.
- Подбор самого быстрого по реальной скорости начинается через 20 с после подключения (было 40 с), в обычном случае через 1 мин (было 2 мин).
- Автопилот на Wi-Fi впервые замеряет скорость через ~5 мин (было 45 мин); если меньше 3 Мбит/с — сам ищет сервер и маску быстрее.
- (из 1.0.98) подключение сразу к 8 лучшим, самый быстрый выбирается каждые 10 с; (из 1.0.97) связь пересобирается сама за ~25 с.

Честно: на реальных телефонах и в российских сетях не проверялось — только автотесты и эмулятор.
