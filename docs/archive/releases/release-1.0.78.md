# VLESS Card 1.0.78 — умный YouTube и ускорение всех режимов

## Авто
- **«Умный YouTube»** (включён по умолчанию, Настройки). После подключения Авто в фоне один раз на каждую сеть сравнивает скорость YouTube через ваши серверы и через обход DPI напрямую к Google (2 замера каждого пути). Если обход заметно быстрее (в 1,3 раза и ещё на 0,5 Мбит/с), YouTube идёт обходом, а всё остальное — через серверы. На главном видно «… · YouTube напрямую через обход DPI». Если YouTube перестал открываться, приложение само вернёт его на серверы.
- **Ротация масок без потери скорости**: маски меняются только на такие же лёгкие или легче той, что прошла замер. Раньше ротация могла поставить «тяжёлую» маску с мелкими пакетами, и видео начинало тормозить.
- **Буфер 64 КБ на соединение** (при «Ускорении телефона»): по умолчанию у Xray на arm64 буфер всего 4 КБ, из-за этого видео упиралось в передачу данных внутри приложения.

## Серверы
- «Проверить» стал быстрее: TCP-пинг идёт по 192 сервера сразу с таймаутом 2 с, проверка через Xray — одна попытка на сервер, вторая только для тех, кто не прошёл, хотя по TCP отвечает.

## Обход DPI (ByeDPI)
- Подбор стратегии быстрее: первый этап — 12 стратегий одновременно, по одной попытке; после 12 рабочих остальные пропускаются (финал всё равно перепроверяет лучших дважды на YouTube, видео-CDN и Discord).

## Честно
- Скорость YouTube меряется загрузкой страницы youtube.com — это приближение к скорости видео-CDN, а не точный замер видео.
- На реальных устройствах и российских сетях эта версия не проверялась: юнит-тесты (59) и проверка конфигураций самим Xray (`xray run -test`).
