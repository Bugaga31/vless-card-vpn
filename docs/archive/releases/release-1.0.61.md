## Скачайте один файл: **VLESS-Card-Beta-1.0.61.apk**
Ставится **поверх** 1.0.60, серверы и настройки сохраняются.

### Режим «Авто» (теперь по умолчанию)
- Одна кнопка «Подключить». Приложение само обновляет подписки (если они старше 12 часов), проверяет серверы и подбирает маскировку тем, что отвечают по TCP, но не открывают сайты. Потом выбирает 5 лучших и подключается.
- Если ни один сервер не работает, подключается **без сервера**, через обход DPI, подобранный для этой сети.
- **Самовосстановление** (Настройки, включено). Если после подключения проверка не прошла, приложение по очереди: берёт следующую рабочую маскировку → заново подбирает маскировку → в «Авто» переходит на обход DPI без сервера. Переподключается само.

### Галочки «Через VPN только: YouTube / Telegram»
- На главном экране. Отмечено — через VPN идут только эти сервисы (Telegram по доменам и по IP-адресам Telegram), всё остальное идёт напрямую.
- В Настройках есть ещё сервисы: Instagram/Facebook, WhatsApp, Discord, X, ChatGPT и др. ИИ, TikTok.
- После подключения проверка показывает: «YouTube: да · Telegram: да». В списке серверов есть отметки YT ✓ / TG ✓.

### Новая маскировка
- **Маски «лесенка» (свои, VLESS Card):** ClientHello режется на куски **разного** размера подряд, так что нет постоянного размера фрагмента, по которому DPI узнал бы маскировку. Три варианта: «1→3→8→30 байт», «шредер зоны SNI» и «1 байт + долгая пауза». Каждый работает с любым отпечатком браузера, напрямую и через обход DPI.
- **UDP-шум для Hysteria2, WireGuard и mKCP (4 маски):** перед рукопожатием отправляются мусорные пакеты: случайные, «под DNS-запрос», «под STUN (звонок)» или много мелких. Сервер их отбрасывает, а DPI видит начало потока не так, как у VPN. Раньше у UDP-серверов маски не было вообще.
- **5 новых стратегий обхода DPI без сервера (свои, VLESS Card × Xray):** лесенка Hello, пыль Hello 1-5 байт, медленный Hello, крупные куски и «1 байт + пауза». Работают внутри приложения, без отдельных бинарников. Участвуют в «Подобрать обход для этой сети». Всего стратегий 26, из них своих 10.
- **Маскировка запоминается для каждой сети:** на Wi-Fi одна, на «Моб.: Beeline» другая. При смене сети VPN переключается сам.
- Всего масок 361.

### Проверено
- Юнит-тесты; все конфиги проходят `xray run -test` (Xray 26.9.30).
- Новые стратегии Xray: все 5 открыли настоящую страницу YouTube (~890 КБ), дробление ClientHello подтверждено на приёмной стороне (15 / 156 / 2 куска).
- WireGuard: локальный WG-сервер Xray, без маски и со всеми 4 масками UDP-шума — 6 из 6 прошли. SOCKS с паролем: напрямую и со всеми лесенками.
- Эмуляторы Android 10 и 13: новые сценарии xraydpi, services (YouTube идёт через сервер, остальное напрямую) и auto (сам проверил и выбрал рабочий сервер). Плюс прежние сценарии.
- На реальном Билайне не проверено.
