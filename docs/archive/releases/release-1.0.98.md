# VLESS Card 1.0.98 — подключение сразу, самый быстрый сервер сам

- Мгновенное подключение: даже если результаты проверки устарели, VPN включается сразу — сразу к 8 лучшим серверам. Балансировщик «самый быстрый» проверяет их каждые 10 с (было 30 с) и сам ведёт трафик через тот, что отвечает быстрее всех; мёртвые отсеиваются за секунды.
- Параллельно идёт быстрая проверка: оставляет 5 самых быстрых и переключается без разрыва VPN, если набор изменился. Если ни один не ответил — сама ищет новые серверы.
- Для скорости по умолчанию уже включено: турбо (крупные пакеты, буферы), блокировка QUIC (YouTube идёт через быстрый TCP), блокировка рекламы, «Умный YouTube» (YouTube напрямую через обход DPI, если так быстрее), автопилот заменяет тяжёлые маски лёгкими и ищет серверы быстрее, если скорость < 3 Мбит/с.
- (из 1.0.97) сам пересобирает связь за ~25 с без ответа; понятные ошибки вместо «A0 was cancelled».

Честно: на реальных телефонах и в российских сетях не проверялось — только автотесты и эмулятор.
