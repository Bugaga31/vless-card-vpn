## Скачайте один файл: **VLESS-Card-Beta-1.0.57.apk**
Ставится **поверх** 1.0.52–1.0.56, настройки сохраняются.

### Новое: «Без сервера (как ByeByeDPI)»
- Кнопка на главном экране. VPN включается **без VLESS-сервера**: трафик всех приложений идёт напрямую, а встроенный обход DPI ломает распознавание ClientHello — как VPN-режим ByeByeDPI.
- Встроены **два движка**: ByeDPI и **zapret tpws** (без root, режим SOCKS). Стратегии перебираются автоматически, пока через туннель **реально не скачается страница YouTube** (≥48 КБ, а не крошечный generate_204, который пропускает даже замедленное соединение).
- Порядок: ваша строка ByeDPI (если задана) → стратегия, сработавшая в прошлый раз → `-o1 -At,r,s -d1` → `-d1` → zapret `--split-pos=1,midsld --disorder` → многократный disorder → своя «VLESS Card» → zapret TLS-записи → … → стратегии с TTL-фейком в конце. Всего 16 стратегий, лимит 2 минуты; рабочая запоминается.
- QUIC (UDP 443) в этом режиме блокируется, чтобы YouTube и браузеры шли по TCP+TLS, который умеет обходить DPI. DNS — Яндекс 77.88.8.8.
- Честно: помогает от **замедления и DPI-блокировки** (YouTube и т.п.), но **не** от блокировки по IP — там нужен рабочий сервер.

### Своя идея маскировки: «VLESS Card · сплит SNI → маскировка»
- Сначала ClientHello режется ровно по SNI + на две TLS-записи + обратный порядок сегментов. Только если DPI ответил сбросом/таймаутом — дополнительно отправляется поддельный ClientHello с доменом маскировки (ya.ru и т.п., TTL 6). Рабочий маршрут подделкой не ломается.

### «Авто» больше не говорит «подключено», когда ничего не работает
- В «Быстрой» проверке «Авто» берёт до 5 серверов с лучшим пингом, но принимает **только тот, через который реально прошёл HTTPS**. Мёртвый сервер — сразу следующий.
- Если ни один сервер не прошёл — «Авто» само переходит в «Без сервера» (переключатель в Настройках → «Без сервера, если серверы не работают», включён по умолчанию).

### Проверено
- JVM-тесты: порядок стратегий, аргументы (слушает только 127.0.0.1 приложения), конфигурация без сервера (TCP → локальный обход, QUIC отклоняется), оценка проверки YouTube.
- Хост-проверка: zapret tpws собран из исходников (коммит c4d0b19), все 6 его стратегий и своя «VLESS Card» проходят HTTPS.
- Эмулятор Android: встроенные libtpws.so/libbyedpi.so с теми же аргументами, что в приложении, — все стратегии передают ClientHello без порчи и ответ обратно; **полный TUN**: отдельное приложение → VPN → ByeDPI/zapret → HTTPS 204 + DNS, по 2 цикла запуска.
- Не проверено (нет доступа из CI): реальная сеть Билайн/других операторов. Если YouTube не пошёл — пришлите текст с главного экрана, там видно, какие стратегии пробовались.

### Исправлено
- В заметках 1.0.56 пример `-d1 -f-1 -t8 -S -n {sni}` содержал `-S` (md5sig), который не работает на ядре Android. Правильно: `-d1 -f-1 -t8 -n {sni} -Qo`.
