## Скачайте один файл: **VLESS-Card-Beta-1.0.63.apk**
Ставится **поверх** 1.0.62, серверы и настройки сохраняются.

### Ключи WARP+
- **Свой ключ:** Настройки → «WARP» → поле «Свой ключ WARP+». Можно вставить один ключ или целый пост из канала с ключами: приложение само найдёт все ключи вида `xxxxxxxx-xxxxxxxx-xxxxxxxx`.
- **Встроенные ключи:** в приложение зашито 135 публичных ключей WARP+ (из @warpplus). Если своего ключа нет или он занят, приложение пробует их по очереди.
- Каждый ключ работает на ограниченном числе устройств. Если ключ занят («Too many connected devices»), берётся следующий.
- Аккаунты с WARP+ называются в списке **«WARP+ …»**. После настройки видно, сколько аккаунтов получили WARP+. Если ни один ключ не подошёл, работает обычный WARP.
- Кнопка «Настроить WARP сейчас» есть и в Настройках, и на вкладке «Серверы» (кнопка «WARP»).

### Проверено
Привязку ключа проверили напрямую через API Cloudflare: первый ключ из списка встал, у аккаунта включился `warp_plus`. Два других ответили «Too many connected devices», их приложение пропускает. Полный путь (регистрация, WARP+, подбор точки входа, подключение) проверяется на эмуляторах Android 10 и 13.
