# VLESS Card 1.0.85 — новый интерфейс

- Главная: большая кнопка подключения сверху — с иконкой, мягким свечением и пульсацией во время подключения.
- Сессия — три плитки: время, скачано, отправлено.
- Быстрые действия после подключения: «Починить», «Ускорить YouTube», «Облегчить маски», «Пауза 5 мин».
- Режим, тип (VPN/прокси), приложения и сервисы собраны в сворачиваемую карточку «Как подключаться» с короткой сводкой.
- Помощник: шапка, «пузыри» сообщений, быстрые подсказки над полем ввода (сеть, YouTube, маски, телефон).
- Плавная смена вкладок.
