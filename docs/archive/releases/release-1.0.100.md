# VLESS Card 1.0.100

**Сторож сервисов.** Открыли Telegram, WhatsApp, Instagram, Discord, X, TikTok, YouTube, ChatGPT, Spotify и т. п. — помощник проверяет через VPN страницу этого сервиса (сразу и каждые 2 минуты, пока приложение на экране). Если она дважды не открылась — сам переключает на другие рабочие серверы и пишет об этом в «Помощник». Если других рабочих нет — запускает «Починить» (маски, оживление серверов, подписки). Нужен включённый автопилот и «Под приложение» (доступ к истории использования).

**Оживление нерабочих серверов.** Многие бесплатные серверы стоят за Cloudflare (ws / xhttp / grpc / httpupgrade + TLS). Когда оператор блокирует их IP, сервер всё равно отвечает на любом другом адресе Cloudflare — его находят по имени (SNI/Host). Приложение пробует мёртвые CDN-серверы на 8 других адресах Cloudflare (случайные из официальных диапазонов + «чистые» домены) и оставляет рабочие копии с пометкой «· CDN». Делается само при починке, или в помощнике: «оживи серверы».
