# VLESS Card 1.1.3

**Сайт не открывается (например, билеты из Telegram) — помощник чинит сам.** Напишите ему адрес сайта (из Telegram: ⋮ → «Копировать ссылку»). Он проверит сайт напрямую, через VPN и через обход DPI и сразу применит решение: российские сайты, которые не пускают иностранные адреса, — всегда напрямую; заблокированные — всегда через VPN. Переподключение без разрыва, отменить можно в «Сайт не открывается?». Раньше решение надо было подтверждать кнопкой. Если написать «сайт не открывается» без адреса — помощник подскажет, как его скопировать.

**Медленно грузится на мобильном — замечается само.** Тест скорости на мобильном не запускается (тратит трафик), поэтому раньше медленность там не ловилась. Теперь раз в 15 минут засекается ответ крошечной страницы через VPN (несколько КБ); если дважды дольше 2,5 с — автопилот ищет серверы и маски быстрее (не чаще раза в 1,5 часа).
