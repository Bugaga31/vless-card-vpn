# VLESS Card 1.0.94 — обходы совершенствуются сами

- Эволюция стратегий ByeDPI 2.0: кроме сдвига чисел стратегии теперь меняют форму — добавляют или убирают целые приёмы (split, disorder, OOB, fake с низким TTL, разрез TLS-записи, другая версия TLS, md5sig; набор взят из открытых рецептов ByeDPI и zapret2) и скрещиваются: потомок берёт начало одной рабочей стратегии и конец другой.
- Общий генофонд: выведенные стратегии, победившие в любой сети, запоминаются (до 20) и проверяются первыми в новой сети и становятся родителями следующих поколений.
- Маски скрещиваются: форма дробления/шума одной рабочей маски + отпечаток, MSS, ALPN, один поток другой; лесенки склеиваются из ступеней двух родителей.
- Отбор: выведенная маска, которая провалилась 6+ раз во всех сетях и почти не проходила, вымирает — место занимают новые.
- Автопилот: эволюция теперь идёт и для обхода DPI — всегда в режиме «Без сервера», через раз в «Гибриде», в «Авто» без серверов.

Честно: на реальных телефонах и в российских сетях не проверялось — только автотесты и эмулятор.
