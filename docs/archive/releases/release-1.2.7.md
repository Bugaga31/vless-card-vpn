# VLESS Card 1.2.7

- **Новые маски WARP: настоящий QUIC-привет к ya.ru и vk.com.** Перед подключением WireGuard/WARP отправляется настоящий пакет HTTP/3 (QUIC Initial по RFC 9001) с ClientHello к сайту из белого списка. ТСПУ умеет расшифровывать такие пакеты и видит обычное HTTP/3-соединение с ya.ru или vk.com. Старая маска «шум под QUIC» внутри была случайными байтами. Идея взята из генератора «Киберпортал» (warp-gen.cyb-portal.org); маски z13 и z14 подбираются автоматически вместе с остальными.
- **Облако берёт серверы «Киберпортала»:** 43 подписки «белых списков» (VLESS Reality / Shadowsocks / Hysteria2 для мобильного интернета), около 20 тысяч ссылок. Каталог читается на лету, новые пакеты добавятся сами. В пробной проверке через Xray работали 121 из 267 серверов, и ни одного из них раньше не было в нашем облаке.
