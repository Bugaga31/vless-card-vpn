## VLESS Card 1.0.59 — пересобрано с нуля

Старое ядро (sing-box) и весь старый код удалены. Новая схема — как в v2rayNG:

**Телефон → VPN → hev-socks5-tunnel → SOCKS 127.0.0.1:10808 → Xray-core 26.9.30 → ваши серверы**

### Что есть
- **Одна большая кнопка** на главной. Режимы: «Серверы», «ByeDPI» (без сервера, как ByeByeDPI), «Гибрид» (YouTube/Discord/Telegram через ByeDPI, остальное через серверы).
- **Список серверов**: вставка ссылок vless / vmess / trojan / ss / hysteria2 и подписок (base64 тоже), бесплатные подписки igareck с зеркал (GitHub, GitLab, Codeberg, jsDelivr).
- **Честная проверка**: TCP-пинг, реальный запрос через Xray, загрузка 256 КБ (ловит «заморозку после 16 КБ» у ТСПУ), YouTube. Много серверов проверяются параллельно.
- **Несколько серверов одновременно**: отмечаете галочками — запросы распределяются между ними (самый быстрый / по очереди / случайно / наименее загруженный), мёртвые выпадают автоматически.
- **168 маскировок**, у каждого сервера своя, работают одновременно: отпечаток браузера (Chrome, Firefox, Safari, Edge, iPhone, Android, QQ) × 12 режимов дробления TLS Hello / первых пакетов × напрямую или через встроенный ByeDPI. «Подобрать маскировку» перебирает до 32 вариантов и оставляет самый быстрый рабочий.
- После подключения приложение само проверяет, что интернет реально идёт через выбранный маршрут, и пишет результат.
- Российские сайты напрямую (по желанию), блокировка рекламы, плитка в шторке, свой порт SOCKS.

### Как начать
1. «Серверы» → «Подписки» (или «Добавить» и вставьте свои ссылки).
2. «Проверить» → «5 лучших» (или отметьте нужные сами).
3. Если сервер не работает — «Подобрать маскировку».
4. Главная → «Подключить».
Если серверы не работают совсем — режим «ByeDPI» (свою стратегию из ByeByeDPI можно вставить в Настройках).

### Что проверено автоматически
- Каждый тип сервера (REALITY+Vision, XHTTP+REALITY, WS+TLS, gRPC+TLS, Trojan, Shadowsocks, VMess) × каждая маскировка — через настоящий Xray-core с реальной загрузкой.
- На эмуляторах Android: другое приложение → VPN → Xray → сервер → интернет (1 МБ, Google, YouTube); по логу сервера видно, что трафик шёл через сервер; при нескольких серверах используются все; режим ByeDPI идёт мимо серверов; встроенная проверка и подбор маскировки дают верный результат.
- Сеть Билайн и реальные заблокированные серверы этим не проверяются.
