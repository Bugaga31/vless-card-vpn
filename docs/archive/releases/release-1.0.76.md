# VLESS Card 1.0.76 — YouTube не уходит на медленный сервер

## Что изменилось

- **В наборе только быстрые серверы.** Раньше «Авто» включал 5 лучших, а встроенный балансировщик Xray («Самый быстрый») выбирает между ними **только по пингу** — и трафик мог уйти на сервер с хорошим пингом, но скоростью 1 Мбит/с. Теперь в набор попадают только серверы, сравнимые с лучшим по пингу и скорости (+ один запасной, если он не безнадёжен).
- **Точный замер скорости на Wi-Fi.** После подключения, в фоне, 5 лучших серверов по очереди качают файл 3 секунды — это близко к тому, что получит YouTube. По этим цифрам «Авто» переранжирует серверы и переключится, если есть быстрее. На мобильном интернете не делается (экономия трафика).
- **Память сетей.** Приложение запоминает, какие серверы работали в каждой сети (дом, работа, мобильный). Вернулись в сеть — сразу эти серверы, без нового поиска.
- **Скорость «сейчас».** На главном экране под сессией — текущая скорость: «Сейчас: ↓ 12 Мбит/с ↑ 0.4 Мбит/с». Видно, тормозит ли VPN во время видео.

## Честно

- На реальных телефонах и в сетях российских операторов не проверялось: только сборка и автотесты (53 теста).
- Точный замер тратит ~5–40 МБ на Wi-Fi один раз после подключения.
