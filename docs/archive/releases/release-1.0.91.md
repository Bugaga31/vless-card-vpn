# VLESS Card 1.0.91 — WARP через сервер

- «WARP через сервер» (Настройки → WARP, или скажите помощнику «включи варп»): телефон → ваш сервер с маскировкой → Cloudflare WARP → интернет. Оператор видит только маску сервера, поэтому WARP работает даже там, где его режут напрямую. Сайты видят адрес Cloudflare — меньше капч и блокировок по IP сервера (полезно для ChatGPT/Gemini).
- Проверено на настоящем Xray 26.9.30: рукопожатие WireGuard уходит через сервер, а не напрямую.
- Помощник: «варп» — если аккаунта WARP нет, сам создаёт его (через обход DPI или VPN, если Cloudflare закрыт) и включает цепочку.
- На главной после подключения — «WARP: включён ✓», если Cloudflare подтвердил, что трафик идёт через WARP.
- Эволюция масок: в новой сети автопилот подбирает и скрещивает маски уже через ~15 минут, а не через 2 часа.
