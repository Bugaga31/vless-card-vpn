# VLESS Card 1.1.8

- **Общее облако.** Телефоны учатся вместе: раз в 6 часов каждый забирает из облака общую мини-нейросеть и маски/обход DPI для своего оператора, а свой анонимный отчёт отправляет автору (что ломалось, какие маски сработали, публичные рабочие серверы). Без номеров, аккаунтов, IP и посещённых сайтов; личные и платные серверы не отправляются. Отключается в Настройках → «Общее облако».
- Облако само проверяет серверы, объединяет отчёты всех телефонов и ставит проверенные телефонами серверы первыми в облачной подписке.
- В эко-режиме обмен с облаком на паузе.
