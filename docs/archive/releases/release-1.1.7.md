# VLESS Card 1.1.7

- **Облако в вашем GitHub.** Настройки → «Облако (ваш GitHub)»: укажите свой приватный репозиторий (например `me/vpn-backup`) и fine‑grained токен с правом *Contents: Read and write* только на этот репозиторий. Приложение само сохраняет туда выученное: маски/маршруты сайтов, память защитника приложений, веса мини‑модели, подписки и серверы (файл `vless-card-backup.txt`) — раз в 3 часа и только если что‑то изменилось. После переустановки «Загрузить из облака» — и ничего не нужно учить заново. Токен хранится только на телефоне и не попадает в резервные копии.
- **Эко‑режим.** При включённой экономии батареи или заряде ниже 20% (и без зарядки) автопилот отключает фоновые проверки скорости, задержки, «оживление» и заморозку — работает только защита от обрывов.
- **Облачная проверка серверов** теперь делает TLS‑рукопожатие для TLS/Reality/Trojan, а не только TCP, и берёт конфиги из большего числа источников (включая Trojan/Shadowsocks).

Честно: общая «облачная база масок» для всех пользователей без своего сервера и секрета невозможна, а облачные машины GitHub стоят за границей и не видят блокировок российских операторов — поэтому финальную проверку всё равно делает телефон.
