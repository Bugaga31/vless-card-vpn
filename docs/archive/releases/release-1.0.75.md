# VLESS Card 1.0.75 — быстрее проверка, быстрее YouTube в «Авто»

## Почему YouTube тормозил

Часть маскировок («узкий канал» MSS 120/88/300, «Невидимка») режет **каждый пакет** соединения до ~100–300 байт, а не только рукопожатие. Страницы при этом открываются быстро и проверка «по пингу» их хвалила, а видео ползло. Сервер выбирался только по пингу — скорость загрузки не учитывалась.

## Что изменилось

- **«Авто» подключается за 10–20 секунд даже без проверок.** Пинг всех серверов разом (1,5 с), настоящая проверка только 30 ближайших (скорость + YouTube) — и сразу подключение к лучшему. Остальные проверяются в фоне через ~40 секунд после подключения; если найдётся быстрее — переключится сам (без обрыва, и не во время видео).
- **«Самый быстрый» = быстрый по-настоящему.** Серверы ранжируются по пингу **и скорости загрузки** (+ работает ли YouTube). Скорость видна в списке серверов («23 Мбит/с») и на главном экране («Лучший: 85 мс · 23 Мбит/с · YouTube ✓»).
- **Проверка в 2–4 раза быстрее.** Большой файл, YouTube и Telegram проверяются одновременно, а не по очереди; вдвое больше серверов параллельно; при «заморозке» ТСПУ второе зеркало не ждём.
- **Умнее подбор маскировки:**
  - лёгкие маскировки пробуются первыми, «тяжёлые» — только если лёгкие не прошли;
  - сначала по одной маскировке **каждого вида** (дробление, лесенки, SNI, MSS, zapret, ByeDPI…), а не дюжина вариантов одного;
  - обучение на ходу: вид, который не прошёл ни на одном сервере, пока другой уже работает, — дальше не перебирается;
  - победитель выбирается по пингу + скорости + «тяжести» маскировки, с повторной проверкой и YouTube.
- **Облегчение маскировки.** Если выбранный сервер работает только с «тяжёлой» маскировкой, после подключения приложение само попробует лёгкие (с замером скорости) и перейдёт, если лёгкая проходит и не медленнее. На главном экране — предупреждение.
- **Чище главный экран.** Тест скорости, «Сайт не открывается?», «Эта сеть» и «Что с сетью?» убраны под кнопку «Инструменты». Во время подключения прогресс виден прямо под кнопкой.

## Честно

- На реальных телефонах и в сетях российских операторов не проверялось: только сборка и автотесты (51 тест).
- Скорость меряется загрузкой 256 КБ — это быстрая оценка, а не полноценный тест; точную цифру даёт «Инструменты → Тест скорости».
- Если в вашей сети работают только «тяжёлые» маскировки, видео всё равно будет медленнее — тогда помогает режим «Гибрид» (YouTube через обход DPI без сервера).
