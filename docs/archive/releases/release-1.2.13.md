# VLESS Card 1.2.13

- **Безопаснее обновления в приложении.** Перед передачей APK установщику проверяются SHA-256 из файла релиза, имя пакета, точный код новой версии и совпадение сертификатов с установленным приложением. Изменённый кеш проверяется снова. Контрольная сумма сама по себе не подтверждает издателя; сертификат проверяется отдельно, Android затем выполняет собственную проверку установки.
- **Надёжнее загрузка.** Скачивание во временный APK; готовый файл заменяется только после проверок. Загрузка по кнопке и фоновая загрузка больше не пишут в один файл одновременно. Неполный/слишком большой файл отклоняется, незавершённая установочная сессия при ошибке закрывается.
- **Без лишнего ожидания после сетевой ошибки.** Повторная автоматическая проверка релиза возможна через 15 минут, а не только через 6 часов. При успешной проверке прежний шестичасовой интервал сохраняется. Некорректные теги и переполнение кода версии отвергаются.
- **Исправлена проверка Android в CI.** В 1.2.12 все 7 проверок Keystore/миграции прошли на Android 11 и 14, но команда без `-r` скрывала служебные счётчики; проверяющий скрипт поэтому остановил релиз. Теперь включён raw-вывод и единая проверка результатов с регрессионным тестом. Число обязательных проверок не уменьшено; отсутствие результата и ошибки по-прежнему блокируют публикацию. Причины ошибок выводятся также в аннотации GitHub.
- Включены все предыдущие улучшения 1.2.12: шифрование локальных секретов и более достоверное обучение. Переносимые резервные копии по-прежнему не зашифрованы. Старый общий ключ из прошлых APK нужно отдельно отозвать; автоматическая отправка отчётов остаётся отключённой.

## Ограничения
- Сертификаты должны точно совпадать: смена ключа подписи требует отдельной запланированной миграции.
- Новые правила проверены JVM-тестами; полный сценарий встроенного обновления на реальном телефоне пока не проверен.
