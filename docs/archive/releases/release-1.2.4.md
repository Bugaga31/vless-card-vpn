# VLESS Card 1.2.4

- **Телефоны делятся замерами по операторам.** В анонимный отчёт добавлено, какие серверы за последние 6 часов реально работали в текущей сети, с какой скоростью, открывался ли YouTube, а какие отвечали на пинг, но ничего не пропускали. Серверы передаются только короткими хешами, без адресов.
- **Облако сводит эти замеры по операторам** (Wi-Fi, «Моб.: beeline» и т. д.). Вес данных падает вдвое за сутки, данные старше 3 дней удаляются.
- **Авто учитывает опыт других телефонов на твоём операторе.** Серверы, которые там раз за разом блокируются, пропускаются, их место занимают следующие ближайшие. Быстрые на этом операторе проверяются в первую очередь. Скорость на твоём операторе важнее скорости, которую облако намерило на GitHub.
