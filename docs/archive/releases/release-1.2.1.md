# VLESS Card 1.2.1

- **Авто-режим больше не сажает всех на один сервер.** У каждого телефона своё постоянное «предпочтение» (до ±20%) между почти одинаковыми серверами, поэтому разные телефоны выбирают разные. Заметно более быстрый сервер всё равно выбирается.
- **Облако распределяет нагрузку.** Телефоны анонимно сообщают, на каких серверах сидят (только короткий хеш адреса, без ссылки). Облако считает, сколько телефонов на каждом сервере за последние 3 часа. Каждый чужой телефон на сервере делает его на 25% «дороже» для автопилота, не больше чем вдвое.
- Облако само проверяет серверы каждые 10 минут: пинг, затем настоящий HTTPS через Xray, с памятью о стабильности серверов.
- В проблемах из отчётов каждый телефон считается один раз.

- Авто снова держит 3–5 серверов (а не один) и распределяет трафик по наименее нагруженному (leastLoad).
