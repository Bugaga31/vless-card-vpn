# VLESS Card 1.0.73

## Новое

- **«Сайт не открывается?»** (главный экран). Введите адрес — приложение откроет его одновременно тремя способами: напрямую, через VPN и через обход DPI, — и скажет, кто виноват:
  - провайдер блокирует сайт, а через VPN он работает → кнопка **«Всегда через VPN»**;
  - сайт не пускает иностранные IP (банки, некоторые российские сервисы) → кнопка **«Всегда напрямую»**;
  - работает только через обход DPI → совет сменить сервер или включить «Гибрид»;
  - сайт не открывается нигде → скорее всего он сам лежит.
- **Свои правила для сайтов.** Выбор «всегда через VPN / всегда напрямую» важнее всех остальных правил (российские сайты напрямую, «только эти сервисы», гибрид). Список и удаление — в Настройках.
- **Резервная копия одной ссылкой** (Настройки → «Резервная копия»). Настройки, свои серверы и WARP, их результаты, выученные маскировки и обходы DPI — в ссылке `vcbackup://`. Сохраните её в Избранное/заметки; на новом телефоне вставьте в «Серверы → Добавить». Подписки в копию не входят — они обновятся сами. В копии ключи серверов, не пересылайте её чужим.

## Честно

- На реальных телефонах и сетях российских операторов эта версия не проверялась: собрана и проверена автотестами (45 тестов), конфиги проверены настоящим Xray 26.9.30.
- Проверка сайта смотрит только на главную страницу по HTTPS; если сайт открывается, а в приложении что-то не грузится — причина может быть в самом приложении.
