# 1.2.31 · Снова на одной волне

## Заставка при каждом открытии

- Беззвучная заставка появляется при новом запуске и при возвращении в приложение из фона, в том числе когда VPN уже работает. Показ не перезапускает и не разрывает туннель.
- Поворот экрана не повторяет уже закрытую заставку. Старый таймер не может закрыть заставку следующего открытия.
- Можно сразу нажать «Открыть приложение»; автоматическое закрытие через 1,8 секунды активного показа. Настройка отключения заставки сохранена.
- Новые мягкие волны и заметная кнопка перехода. Движение ограничено, учитывает энергосбережение и системное отключение анимации.

## Маски: приоритет реальным результатам

- Добавлены четыре дополнительных Hello-only профиля для VK, ya.ru, Яндекса и VK Видео: фрагменты 40–80 байт, задержка 0–1 мс, без мелкого MSS для всего трафика. Это варианты для проверки, а не гарантия обхода блокировки.
- Подмена SNI по-прежнему разрешена только для совместимого TLS с закреплённым сертификатом. REALITY SNI и проверка сертификата не ослабляются.
- Облачные подсказки, сохранённые маски и новые мутанты проходят одинаковую проверку совместимости, пользовательских фильтров и доступности движков ByeDPI/TPWS.
- Одна старая удача не поднимает постоянно падающую маску в начало списка. Повторные успехи имеют больший приоритет; неудачные варианты не удаляются навсегда.
- При повторной проверке учитывается измеренная скорость настоящего видео, если она известна, иначе общая скорость. Неизмеренная скорость не считается быстрой. Тяжёлые маски получают дополнительный штраф.

## Главный экран и проверка интерфейса

- Компактная строка версии Xray, немного меньшая кнопка подключения, контур карточки по состоянию связи. Показано фактическое количество выбранных и всех конфигураций, есть переход к серверам.
- Нативные снимки CI проверяют фокус приложения и не принимают окно лаунчера или системный диалог за интерфейс VLESS Card. Возврат из фона проверяется отдельным сценарием.
- Добавлены регрессии жизненного цикла заставки, безопасных SNI, пользовательских фильтров и ранжирования скорости.

Работа масок зависит от сервера и сети оператора. Нет обещания ускорения любого телефона, обхода любых блокировок или удаления встроенной рекламы YouTube. Нативная визуальная проверка и проверка на реальном устройстве необходимы отдельно от JVM-тестов.
