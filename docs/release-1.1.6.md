# VLESS Card 1.1.6

**Обновление стало быстрее и незаметнее.** С 1.1.5 новые версии ставятся из приложения (без GitHub). Теперь ещё:
- На Wi-Fi новая версия скачивается заранее, в фоне: «Обновить» → установка за секунды. На мобильном интернете трафик заранее не тратится — скачивается только по кнопке.
- Проверка новых версий идёт и пока приложение закрыто, а VPN работает (раз в 6 часов); помощник пишет «Вышла версия …».
- Это первая версия, которую можно поставить из 1.1.5 кнопкой «Обновить» на главной.
