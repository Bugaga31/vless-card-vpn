# VLESS Card 1.0.88 — новый помощник и эволюция масок

- «Помощник» с новым дизайном: шапка со статусом автопилота, живая панель (связь, текущая маска, лучший сервер), переключатели «Автопилот», «Под приложение», «GPS», «Умный YouTube» прямо в чате.
- «Что я сделал сам» — журнал действий автопилота с временем.
- Сообщения с аватаром, градиентные «пузыри», кнопки-действия в несколько строк, живой прогресс текущей задачи с кнопкой «Стоп».
- Быстрые подсказки: улучшить соединение, ускорить YouTube, подобрать/сменить маску, сеть, телефон.
- Автопилот: «эволюция масок» — раз в 2 часа, пока связь в порядке, скрещивает и проверяет мутантов рабочих масок этой сети (до 3 серверов, 12 вариантов на сервер); прошедшие становятся запасными масками.
