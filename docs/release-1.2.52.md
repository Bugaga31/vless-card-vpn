# VLESS Card 1.2.52

Новый выпуск уже подготовленного кандидата. После команды завершить выпуск дополнительные исправления в исходники приложения не добавлялись.

## Состав кандидата
- Подготовленные ранее исправления запуска, готовности и остановки встроенного Tor.
- Проверка управляющих строк в torrc/ControlPort и отказ от молчаливой замены неподдерживаемого транспорта обычным Tor.
- Подготовленные ранее исправления Android API-совместимости и подписок Compose на состояние; дизайн не перерабатывался.
- Публикация зависит от E2E API 29/33, masks matrix, JVM, release lint, подписанных APK и установочных проверок API 30/34 на SHA этого выпуска.
- Сертификат подписи должен совпадать с опубликованной 1.2.50. Проверяется установка обновлением с 1.2.50.
- verification.json содержит SHA исходников, результаты JVM/lint и хеши APK.

## Ограничения
- Поддерживаемые встроенные транспорты: обычный Tor, obfs4, WebTunnel. Snowflake и Meek этим выпуском не добавлены; для сохранённого неподдерживаемого режима нужно выбрать поддерживаемый транспорт.
- Встроенный Tor работает от UID приложения. Автоматическая цепочка Tor поверх VLESS не считается доказанной этим выпуском. Произвольный UDP через Tor и Discord-голос не обещаются.
- Офлайн-проверка нативного Tor (--version/--verify-config с DisableNetwork) не заменяет bootstrap и проверку настоящих мостов.
- Физический телефон, сети владельца, реальные сообщения Telegram и воспроизведение YouTube не проверены одним CI. Доступность у конкретного оператора и мгновенное подключение не гарантируются.
- UNKNOWN не является PASS; HTTPS-ответ сайта не заменяет MTProto или передачу видео.
