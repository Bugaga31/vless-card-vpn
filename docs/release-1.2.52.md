# VLESS Card 1.2.52

Исправленный кандидат после неизменяемого выпуска 1.2.51. Публикация разрешена только после успешных обязательных проверок на итоговом SHA.

## Строгие проверки и скорость
- Fast Auto требует завершённую передачу 256 KiB, а не только HTTPS-заголовок/204. Замер скорости выполняется последовательно у ограниченного числа финалистов, двумя окнами тела ответа; оценка не выше более медленного окна и общей скорости с учётом установки соединения.
- HTML/JSON вместо бинарных данных, неправильный Content-Range, незавершённая передача и превышение дедлайна не дают доказательства скорости.
- Для видео требуется разрешённый HTTPS googlevideo URL, корректный диапазон, MP4/WebM-заголовок контейнера и передача 128 KiB. Это не заменяет воспроизведение на физическом телефоне.
- MTProto требует совпадения nonce, корректной структуры/длины, серверного nonce, pq и вектора fingerprints. Это проверка достижимости протокола, не вход в аккаунт и не полноценная аутентификация Telegram.
- Явный Telegram/YouTube FAIL исключает Auto-маршрут даже тогда, когда других кандидатов не осталось. UNKNOWN остаётся UNKNOWN, а не PASS.
- Auto предпочитает одного лидера по свежей локально измеренной скорости; резервные outbounds остаются под наблюдением. Полный каталог не проверяется синхронно и абсолютный «самый быстрый в интернете» не обещается.

## Tor-мосты
- Ручная загрузка выбранного транспорта obfs4/WebTunnel из https://raw.githack.com/igareck/vpn-configs-for-russia/main/TOR-BRIDGES/TOR_BRIDGES_TOP100.txt (источник: igareck/vpn-configs-for-russia).
- Нормализация строк с префиксом Bridge и без него, фильтрация неподдерживаемых/некорректных записей, защита от внедрения директив, ограничение ответа 256 KiB и до 12 мостов выбранного транспорта.
- Ошибка загрузки не удаляет сохранённые строки. Смена режима во время запроса не заменяет мосты неожиданно. Автообновления, случайного сканирования и молчаливого перехода на прямой Tor нет.
- Название TOP100 — заявление стороннего источника, не подтверждённый рейтинг приложения. Офлайн-проверка формата не доказывает bootstrap или доступность моста в сети владельца.

## Исправления
- Tor не отключается молча при отсутствии VLESS-серверов; выбранные TCP-сервисы направляются в Tor без зависимости от ранее обученных привязок серверов.
- Режим Tor для всего трафика имеет приоритет над Hybrid DPI, пулами тяжёлого трафика и сервисными привязками. Пользовательские прямые исключения сохраняются.
- Успех Tor/смешанного маршрута не записывается как доказательство работоспособности выбранного VLESS-сервера; статус WARP не выводится на основании Tor-проверки.
- Ручной выбор нескольких серверов и собственных маскировок не обрезается правилом разнообразия Auto. Само правило разнообразия Auto не ослабляется.
- Исправлены запуск, готовность, остановка и отмена встроенного Tor, валидация ControlPort/мостов и Android API-совместимость.
- Дополнены регрессии маршрутизации, доказательности проверки и изоляции debug fixtures. Сценарий восьми аутентифицированных Xray outbounds использует отдельные синтетические имена; это не доказательство восьми независимых операторов/выходов.

## Релизные барьеры
E2E API 29/33, masks matrix, полный JVM-набор (не менее 468), release lint, сборка/подпись и установка обновлением с 1.2.50 на API 30/34. Сертификат должен совпадать с 1.2.50. verification.json содержит SHA исходников, результаты JVM/lint и хеши APK. Debug fixture aliases отсутствуют в release APK и отдельно проверяются.

## Ограничения
- Встроенные транспорты: обычный Tor, obfs4 и WebTunnel. Snowflake/Meek не добавлены; неподдерживаемая конфигурация не заменяется обычным Tor молча.
- Автоматическая цепочка Tor поверх VLESS не реализована и не заявляется. Произвольный UDP через Tor, Discord-голос и абсолютная анонимность не гарантируются. Прямые исключения настроек сохраняются.
- Офлайн-проверка нативного Tor (--version/--verify-config с DisableNetwork) не заменяет bootstrap и проверку настоящих мостов.
- Физический телефон, сети владельца, реальные сообщения Telegram и воспроизведение YouTube одним CI не проверяются. Доступность у оператора и мгновенное подключение не обещаются.
- UNKNOWN не является PASS; HTTPS-ответ сайта не заменяет MTProto или передачу видео.
