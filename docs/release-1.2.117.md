# VLESS Card Experimental 1.2.117

Пакет com.vlesscardvpn.beta2, versionCode 228, постоянная подпись Beta. Устанавливать поверх Beta2 без удаления.

## Изменения
- После успешного подключения полный профиль сервисов больше не запускается по таймеру. Прекращено постоянное пополнение резервов при здоровом соединении.
- Истёкший замер отображается как устаревший, но не как несуществующая текущая проверка. Допуск старого доказательства не продлевается.
- Лёгкий HTTPS/DNS контроль остаётся: в Auto 10–15 с при активном экране, 20 с при выключенном; бюджет 3,5 с. Реальный отказ, смена сети/профиля и подозрение зависшего трафика обрабатываются отдельно. Это не обещание точного времени восстановления в Android Doze.
- Выбранный сервис с подтверждённым FAIL может запустить восстановление; UNKNOWN не считается отказом. Защита активного звонка сохранена.
- Текущие проверки и статусы подняты на главном экране; кнопка отключения остаётся доступной. Проверочный SOCKS и системный TUN показаны отдельно.
- ROKI меняет порядок только после 8 определённых наблюдений и минимум двух успехов/двух отказов; близкие оценки сохраняют исходный порядок. Он не меняет строгий допуск сервисов.
- ВАТСОН автоматически ограничивает только необязательную работу приложения. Скрытый UI собирает лёгкий срез не чаще 120 с; тяжёлая инвентаризация выполняется только при видимом UI и разрешённом фоне. Окно обучения сбрасывается при явном поиске, чтобы нагрев от проб не искажал метки.

## Границы
YouTube — одиночный HTTP-запрос доступности, не подтверждение воспроизведения видео. UDP/STUN не равен реальному разговору. Серверные ключи, SNI, транспорт, параллелизм 1/3/5/10 и строгие обязательные сервисы сохранены. Нет измерений на телефоне владельца, экономии батареи, ускорения зарядки, физического охлаждения, Doze, полного TUN или утечек. Результаты фактической сборки и ограниченных проверок находятся в verification.json. Не весь набор JVM/lint/UI проверок проекта.
