# VLESS Card 1.2.5

- **Telegram больше не ломается «через раз».** С 1.2.1 Авто распределяет трафик между 3–5 серверами, и если среди них был сервер, через который Telegram не ходит (в проверке «TG ✗»), часть соединений Telegram попадала на него. Теперь такие серверы не выбираются, пока есть другие.
- **«Гибрид»: Telegram идёт через серверы, а не через обход DPI.** Telegram в России блокируют по IP, а обход DPI от этого не спасает: картинки и видео из cdn telesco.pe зависали. Это поправлено и у тех, у кого стояли старые настройки.
- **Без ложной тревоги сразу после подключения.** Если первая проверка не прошла (WireGuard/WARP ещё устанавливает соединение, медленный мобильный интернет), через 3 секунды она повторяется, и только потом приложение начинает «чинить» или переподключаться. Проверка WARP у Cloudflare тоже повторяется.
- Тесты на GitHub перепроверяют по одной маски, упавшие под нагрузкой, так что ошибки нагрузки больше не маскируют настоящие поломки.
