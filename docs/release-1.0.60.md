## Скачайте один файл: **VLESS-Card-Beta-1.0.60.apk**
Ставится **поверх** 1.0.59, серверы и настройки сохраняются.

### Маскировка трафика: 315 масок, свои + zapret + ByeDPI перед сервером
- Соединение с сервером теперь можно провести через любую из 21 стратегии обхода DPI: провайдер видит ClientHello, порезанный и перемешанный, иногда с поддельным SNI (ya.ru, vk.com, gosuslugi.ru…).
- **Свои стратегии VLESS Card (5):** адаптивный каскад, шредер SNI, сплит SNI → маскировка, другая версия TLS-записи, шредер хоста (zapret).
- **zapret tpws (7)** и **ByeDPI (9)**, популярные строки из ByeByeDPI.
- Каждая маска = отпечаток браузера (Chrome, Firefox, Safari, Edge, iPhone, Android, QQ) × дробление TLS × стратегия. Всего 315.
- У разных серверов могут быть разные маски одновременно: для каждой стратегии запускается свой движок.
- «Подобрать маскировку» перебирает до 48 масок на сервер и оставляет самую быструю из реально работающих. Ещё 6 рабочих запоминаются.
- **Менять маскировку при каждом подключении** (Настройки → Несколько серверов): берётся случайная из рабочих, так что у трафика нет постоянного отпечатка.

### Обход DPI без сервера (ByeDPI + zapret), как в ByeByeDPI
- «Подобрать обход для этой сети» проверяет все стратегии плюс вашу строку, по 4 сразу. Стратегия считается рабочей, только если через неё **скачалась настоящая страница YouTube** (≥48 КБ).
- Рабочая стратегия запоминается **для каждой сети отдельно** (Wi-Fi, «Моб.: Beeline»…). При смене сети VPN сам переключается на стратегию, найденную для этой сети.
- Можно выбрать стратегию вручную или вписать свою строку ByeByeDPI. Домен маскировки выбирается.

### Скрытность
- **Скрытый локальный прокси** (включено): при каждом подключении случайный порт и случайные логин/пароль. Приложения, которые ищут VPN сканированием 127.0.0.1:10808, его не найдут и не смогут им воспользоваться.
- **Приложения без VPN:** банки, Госуслуги, маркетплейсы, VK, Яндекс, операторы отмечаются одной кнопкой. Есть режим «только отмеченные через VPN».
- **Российские сайты напрямую** + **DNS для .ru через Яндекс**: российские сервисы видят обычного абонента. Остальной DNS идёт зашифрованным через туннель (Cloudflare, Google, Quad9 или AdGuard).
- **Блокировать QUIC**: трафик идёт по TCP+TLS, который маскируется. **Блокировать WebRTC/STUN**: по умолчанию выключено, потому что ломает звонки.
- **Иконка-маскировка**: «Калькулятор», «Заметки», «Погода». **Нейтральное уведомление**: «Синхронизация · Активно».
- **Kill switch**: кнопка открывает системные настройки «Постоянная VPN» и «Блокировать без VPN».
- **Стереть все данные** одной кнопкой.
- **Mux** (мультиплексирование) для серверов без Vision/XHTTP.

### «Что с сетью?» на главном экране
- Проверка напрямую: российские сайты, зарубежные сайты и настоящая страница YouTube.
- Вердикты: «белые списки» (открыто только российское) → кнопка «Серверы для белых списков», которая загружает, проверяет и выбирает 5 лучших. «YouTube режут (DPI)» → кнопка «Подобрать обход».

- Все конфигурации проходят `xray run -test` (Xray 26.9.30).
