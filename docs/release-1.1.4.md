# VLESS Card 1.1.4

**«Нет соединения» в Chrome на разных телефонах — исправлено (две причины).**
- **IPv6.** VPN пускал IPv6 в туннель, а там его отбрасывал. Chrome при этом видел «установленное» соединение, которое тут же обрывалось, и писал «нет соединения» вместо того, чтобы открыть сайт по IPv4. Теперь IPv6 в туннель не идёт: Android сразу отказывает в IPv6, и Chrome мгновенно открывает сайт по IPv4. Утечки нет — Android блокирует IPv6 мимо VPN.
- **«Безопасный DNS» Chrome и «Частный DNS» Android.** VPN объявлял DNS-серверы 1.1.1.1 и 8.8.8.8 — для них Chrome и Android сами включают свой шифрованный DNS мимо DNS приложения, который отдаёт IPv6-адреса (см. выше) и иногда не проходит. Теперь DNS — адрес внутри туннеля, браузер пользуется DNS VPN.
- **Потеря сети.** Когда сеть пропадает, VPN больше не держится за исчезнувшую сеть, а сразу следует за той, что стала основной.
