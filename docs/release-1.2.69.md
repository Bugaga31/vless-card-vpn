# VLESS Card 1.2.69 · Experimental — управление и прозрачность Авто

## Новые инструменты на главном экране
- «Починить Telegram»: в обычном Авто запускает ограниченную отдельную проверку текущего сервера и резервов. При ручном запросе предпочитает другой прямо сейчас подтверждённый маршрут, если такой найден. Не трогает аккаунт Telegram, не включает прямой обход и не перезапускает обычное подключение через общий ACTION_START.
- «Без фонового ускорения 30 мин»: временно приостанавливает фоновое сравнение/скоростную оптимизацию, исследование цепочек и необязательные maintenance-переподключения. VPN, проверка доступности, смена физической сети и аварийное восстановление остаются активны. Это не гарантия отсутствия любого переподключения при сбое. Можно снять паузу вручную; состояние только в памяти процесса.
- «Паспорт соединения»: отдельные результаты HTTPS, DNS через SOCKS UDP, sampled Telegram MTProto и sampled YouTube media. Неопределённый результат не превращается в успех; результаты старше 90 секунд помечаются устаревшими.
- Паспорт отправляется только нажатием «Поделиться»: фиксированный JSON без адресов серверов, subscription URL, ключей, токенов, сырого журнала, названий сетей или аккаунтов. Никакой автоматической отправки.

## Ограничения
Паспорт описывает локальные пробы через SOCKS, а не независимое доказательство пути приложения через Android TUN. Проба Telegram не подтверждает авторизацию, все DC, файлы или звонки. Кнопка восстановления предназначена для обычного Авто без отдельного Tor-маршрута Telegram; защита обнаруженного звонка и ограничение частоты сохраняются. Заявления о лидерстве, монополии, гарантированной скорости и работе у всех операторов не делаются.

На базе 1.2.68 сохранены single-primary, проверенные резервы, отсрочка MTProto-отказов и порог переключения по скорости. По просьбе владельца unit-тесты, lint, эмулятор и телефон не запускались. Только компиляция, подпись постоянным Beta-ключом и проверка целостности APK. Стабильный канал и старые APK не заменены.
