# VLESS Card 1.2.138

Обычный релиз. Пакет com.vlesscardvpn.beta2, versionCode 249; ставится поверх прошлых версий с той же подписью.

## Поиск и проверка серверов
- Быстрый предварительный TCP-этап поддерживает настройку до 1000 одновременных соединений. Фактическое число ограничивается доступными ресурсами телефона. Сам TCP-тест ещё не подтверждает, что VPN работает.
- Полная проверка через Xray идёт волнами и ограничивает количество параллельных проверок. Перед большой проверкой приложение предупреждает о возможном расходе времени и трафика.
- Неответившие серверы проверяются повторно. Двукратный сбой записывается только при подтверждённой доступности сети; неопределённый результат не объявляет сервер неисправным.
- Если первый проверенный кандидат не удалось выбрать для подключения, поиск продолжится, а не остановится на нём.
- При сравнении цепочек время запуска ядра учитывается в лимите проверки: запросам передаётся только оставшееся время. Если лимит уже истёк, ресурсы закрываются и проверка переходит к следующему кандидату.

## Восстановление и Tor
- Защита от повторного одновременного перезапуска и более устойчивые таймеры восстановления. На Android 11 и новее доступна локальная подсказка о последней причине закрытия процесса, если система её предоставила.
- Если автоматическое обновление мостов разрешено и сохранённых мостов obfs4 нет, встроенные мосты Tor Project подготавливаются без ожидания загрузки списка; обновление запускается в фоне. Для WebTunnel при отсутствии встроенных мостов остаётся загрузка из источника.
- **Tor первым узлом не реализован**: текущая цепочка остаётся VLESS → Tor. Провайдер видит адрес первого узла; полная незаметность не гарантируется.

## Что проверено до публикации
- На предыдущем коммите прошли 2360 debug JVM-тестов и 2359 release JVM-тестов, lint, 92 теста release-gates и 104 теста инструментов E2E. Матрица масок и E2E на Android API 29 и 33 также проходили; проверены автоматическая цепочка и восстановление в фоне. После этого уточнён расчёт времени проверки цепочек и расширена диагностика.
- Ранее встречались единичные сбои тестов маскировки и оптимизатора; последующие прогоны прошли, но причины этих сбоев не установлены. WARP+ предупреждает, если свободный ключ недоступен.

Работа с реальными мостами Tor, на настоящем телефоне и в сетях операторов этой версией не проверялась. Причина конкретного закрытия приложения пока неизвестна.
