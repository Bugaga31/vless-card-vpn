# 1.2.22 — публичное облако в очереди Xray

- До двух облачных претендентов в ограниченных очередях холодного старта, перепроверки и фонового поиска, рядом с локальным лидером.
- Манифест сохраняет отдельную дату измерения скорости; устаревшие/недатированные значения не выдаются за свежие.
- Переключатель публичного облака отключает его подсказки и загрузки, не затрагивая личный backup.
- Одна совместная операция обновления вместо конкурирующих refresh-задач; ручная кнопка в настройках использует те же ограничения частоты и питания.
- Тексты описывают Xray, проверку на телефоне и отключённую отправку отчётов без обещаний чужого обучения.

Без root оптимизируется нагрузка самого клиента; приложение не разгоняет процессор и не управляет чужими приложениями.
