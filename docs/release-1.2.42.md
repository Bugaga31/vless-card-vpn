# 1.2.42 — Tor-режим: мосты, «Tor в Авто», ассистент

## Что нового

- **Мосты Tor**: в настройках Tor-режима — выбор транспорта: без мостов / obfs4 / Snowflake. Snowflake работает сразу (встроенная линия моста и рабочие параметры клиента в torrc Termux); для obfs4 — кнопка «Получить мосты» открывает bridges.torproject.org, мосты вставляются в torrc Termux.
- **«Tor в Авто»**: если выбранный сервис перестаёт работать через все серверы (маршрутизация сервисов меряет это постоянно), приложение само переключает его на локальный Tor — связь восстанавливается без вашего участия, пока VLESS-маршруты снова не заработают.
- **Ассистент**: спрашивайте «тор», «мосты», «анонимно» — включит Tor-режим по кнопке, подскажет про мосты.
- Настройки: тумблеры «Tor для сервисов», «Tor в Авто», чипы мостов — в разделе «Tor» на экране настроек.

## Как это работает

Выбранные сервисы (Discord и др.) идут через локальный Tor в Termux, а сам Tor
едет внутри VPN-туннеля: сайты видят адрес Tor-выхода, оператор — только
маскированный VLESS. Выход Tor ротируется каждые ~10 минут, страны выхода
подстраиваются под ваши привычки.
