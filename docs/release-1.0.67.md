## Какой файл скачать
- **VLESS-Card-Beta-1.0.67-arm64.apk** — для почти всех телефонов (64-битных).
- **VLESS-Card-Beta-1.0.67.apk** — универсальный, если arm64-файл не ставится.

Ставится **поверх** 1.0.66, настройки и серверы сохраняются.

### Авто-режим больше не сдаётся
- **«Подключить» срабатывает сразу**: если что-то уже работало, приложение подключается мгновенно, а проверяет и ускоряет потом, в фоне. Раньше кнопка могла молча ждать, пока закончится фоновая подготовка.
- **Сторож связи**: каждые 45 секунд приложение делает лёгкий запрос через VPN. Если связь пропала два раза подряд, оно само начинает искать замену, не дожидаясь, пока вы заметите.
- **Поиск идёт по шагам, пока не найдётся рабочий вариант**:
  1. другая маскировка из уже проверенных;
  2. другие рабочие серверы;
  3. подбор маскировки, включая эволюцию масок;
  4. свежие подписки, перепроверка всех серверов и WARP.
- Если серверы не нашлись, приложение временно работает через обход DPI без сервера и **каждые 3 минуты продолжает искать** серверы. Как только они найдутся, оно само вернётся на них.
- Если пропал интернет у самой сети (лифт, метро), приложение не ломает настройки, а ждёт, когда сеть вернётся.
- На главном экране видно, какой шаг поиска сейчас идёт.

### Маскировка — авто
- Маскировка подбирается сама. «Выбрать вручную» и «Сделать свою» убраны в «Для опытных».
- **Двойная проверка**: найденная маскировка проверяется ещё раз, уже с YouTube. Побеждает та, что прошла дважды, а не случайно проскочившая один раз.
- «Проверить» на вкладке «Серверы» сам подбирает маскировку, если рабочих серверов меньше 5.
- На главном экране видно, какая маскировка сейчас используется.

### WARP: видно, работает или нет
- После «Настроить WARP» приложение само подключается.
- В строке проверки сам Cloudflare подтверждает: **«WARP: включён ✓»** или **«WARP+: включён ✓»**, либо пишет, что трафик идёт не через Cloudflare.

### Без подвисаний
- Проверки и подбор масок идут в фоновых потоках с низким приоритетом. Интерфейс больше не борется с ними за процессор.
- Главный экран и настройки не перерисовываются из-за каждого результата проверки. Нажатия срабатывают сразу.
- Во время большой проверки файл с данными сохраняется раз в несколько секунд, а не после каждой пачки результатов.
