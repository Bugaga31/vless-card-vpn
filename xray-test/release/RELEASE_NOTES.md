# VLESS Card Test — Xray / экспериментальный выпуск

**Скачать и установить: VLESS-Card-Test-Xray.apk.** Это отдельное приложение с названием **VLESS Card Test**, а не обновление старого sing-box приложения. Работоспособность VPN на реальном устройстве ещё не подтверждена.

## Первый запуск
1. Отключи другой VPN. Старое приложение не удаляй.
2. Импортируй свою заведомо рабочую VLESS-ссылку. Конфигурации старого приложения автоматически не копируются.
3. Для первого теста выключи «Авто», разреши HTTPS-проверки и нажми «Подключить выбранный».
4. Разреши создание VPN в системном окне Android. Проверь браузер, Telegram и YouTube, затем отключение и повторное подключение.
5. Для теста авто импортируй несколько своих серверов: приложение перебирает их до первого прошедшего проверки. Это не выбор самого быстрого сервера.
6. Если случится вылет: открой приложение снова → «Отчёт о подключении / вылете» → «Скопировать». Проверь отчёт перед отправкой.

## Важно
- В этом первом прототипе ссылки хранятся только в памяти; после завершения процесса их нужно импортировать заново.
- Поддерживаются VLESS TLS/REALITY с TCP/raw, WebSocket и gRPC. XHTTP и другие неподдерживаемые параметры отклоняются, а не заменяются молча.
- Проверки Telegram относятся к веб-сайту, YouTube — к HTTPS generate_204. Они не проверяют сообщения, звонки или воспроизведение видео.
- Проверки направлены через SOCKS Xray; сами по себе они не доказывают, что TUN правильно передаёт трафик других приложений. Это проверяется на устройстве.
- После трёх неудачных раундов и паузы не менее 60 секунд авто ищет замену. Выход приложения из процесса/перезагрузка не запускают VPN заново.
- Это НЕ kill switch. После остановки/ошибки/завершения процесса Android может восстановить прямой доступ. Не используй тестовую сборку для чувствительных действий.
- Нет утверждения, что старый вылет или старый авто-режим исправлены. Это новый вариант интеграции для сравнения.
