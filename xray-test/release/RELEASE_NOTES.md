# VLESS Card Test — Private Lounge на Xray

**APK: VLESS-Card-Test-Xray.apk.** Это отдельное тестовое приложение, не обновление старой версии на sing-box. Пользователь сообщил, что базовое подключение в предыдущем Xray-прототипе работает; новый интерфейс, хранилище и все сценарии авто ещё требуют проверки на телефоне.

## Что добавлено
- Private Lounge: графитово-зелёные карточки, шампанские акценты и разделы Главная / Серверы / Источники / Авто / Отчёт.
- Импорт обычных VLESS-списков и Base64-подписок. Неподдерживаемые строки пропускаются с количеством; поддерживаемые не теряются из-за одной плохой строки.
- Загрузка четырёх публичных VLESS-источников из прежнего приложения: только после отдельного согласия, с отменой, лимитом ответа и без перехода по вложенным адресам.
- Коллекция до 50 серверов, удаление с подтверждением, избранное и ручной выбор.
- Сохранение коллекции и избранного в AES-GCM с ключом Android Keystore и атомарной записью. При ошибке чтения список не сбрасывается автоматически.
- Управление существующим авто-подключением Xray, включая режим «только избранные». Пустое избранное не подменяется всеми серверами.
- Сохранена поддержка TCP HTTP header, TLS/REALITY, TCP/raw, WebSocket и gRPC. XHTTP и неподдерживаемые параметры не подменяются молча.

## Проверка на телефоне
1. В «Серверы» импортируй свою заведомо рабочую ссылку; выбери сервер, разреши HTTPS-проверки на главной и подключись вручную.
2. Проверь браузер, Telegram, YouTube, отключение и повторное подключение.
3. Перезапусти приложение: импортированная коллекция и звёзды должны сохраниться. Профили из самых первых memory-only тестовых сборок нужно импортировать один раз заново.
4. В «Источники» ознакомься с предупреждением и разреши загрузку. Добавленные публичные узлы ещё не считаются рабочими.
5. В «Авто» выбери режим и при необходимости только избранные. Проверка идёт до первого прошедшего оба HTTPS-теста сервера, не до самого быстрого. Изменять список и режим нужно после отключения.
6. При проблеме открой «Отчёт», скопируй его и проверь перед отправкой. Не отправляй полную VLESS-ссылку.

## Ограничения
- Публичные источники и их VPN-операторы не считаются доверенными. Загрузка источников идёт из исключённого из VPN приложения; GitHub видит внешний IP. Не используй публичные узлы для чувствительных действий.
- Telegram проверяется по веб-сайту, YouTube по HTTPS generate_204. Это не тест звонков, сообщений или видео. Успешный SOCKS-тест не доказывает передачу трафика остальных приложений через TUN.
- Нет kill switch, автозапуска после перезагрузки и автоматического переноса данных из старого sing-box приложения. После остановки VPN Android может восстановить прямой доступ.
- Ошибка запуска ядра останавливает попытку. Переключение после повторных сбоев может прервать текущие соединения.
- Это тестовый debug APK. При конфликте подписей не удаляй приложение без сохранения нужных ссылок.
