# Релиз VLESS Card VPN на ядре Xray (v1.1)

### Что сделано и улучшено:
- ⚡ **Ускорено подключение и диагностика:** время предварительного теста сокращено с 7с до 2.5–3.5с. Авто-переключение узлов при сбоях теперь срабатывает быстрее и точнее (порог 2 раунда / 20 сек).
- 🚀 **Оптимизирована маршрутизация Xray:** отключен ресурсоемкий Mux для чистого throughput, прописаны быстрые upstream DNS (1.1.1.1, 8.8.8.8) со стратегией `UseIPv4` для снижения задержек.
- 🛡 **Полноценная конфигурация outbounds:** добавлены корректные `direct` (freedom) и `block` (blackhole) outbounds для чистоты схемы ядра.
- 🔒 **Надежный запуск ForegroundService:** обновлены тексты уведомления, обеспечено безопасное управление жизненным циклом и освобождение ресурсов при разрыве или смене сервера.

### Артефакты сборки:
- `VLESS-Card-Xray.apk` — готовый установочный файл APK.
- `SHA256SUMS.txt` — контрольные суммы sha256 для проверки целостности.
- `VLESS-Card-Test-Xray-sources.zip` — исходный архив с зависимостями.
