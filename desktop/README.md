# VLESS Card · Xray — Windows preview 0.2.0

Начальная Windows x64-версия, не перенос всех возможностей Android.

- Портативный WinForms EXE (.NET 8 включён) и закреплённое официальное Xray-core v26.9.30.
- Импорт текстовых/Base64-подписок и VLESS TCP/raw + TLS/Reality. Другие транспорты отвергаются, не подменяются.
- Чтение публичного облака с проверкой срока манифеста; скорость из облака — только порядок кандидатов.
- Локальный SOCKS5 только на 127.0.0.1, случайный порт и новые учётные данные каждой сессии.
- Подключение подтверждается HTTPS-запросом через SOCKS, а не только открытым TCP-портом.
- Не изменяет системный прокси, не устанавливает драйверы, не запрашивает администратора. Настройте SOCKS5 в нужном приложении.
- Ключи конфигурации временно записываются в профиль текущего пользователя и удаляются при штатной остановке. Аварийное завершение/отключение питания может оставить файл в `%LOCALAPPDATA%/VlessCard/sessions`; это не зашифрованное хранилище.
- EXE пока без подписи издателя. Не отключайте защиту Windows ради запуска.

Пока **нет** TUN/общесистемного VPN, полного Android-алгоритма автоподбора, автообновления, ByeDPI/WARP-цепочек и диагностики/оптимизации телефона. Успешная сборка и smoke-тест не доказывают работу у каждого оператора.

CI проверяет парсер, конфигурацию закреплённым Xray и запуск окна. Результат — отдельный Windows preview ZIP; Android APK не подменяется Windows-сборкой.

## Автоподбор 0.2.0
Кнопка «Авто · найти быстрее» загружает публичный манифест, если каталог пуст. Быстрый TCP-отсев ограничен 24 кандидатами, четырьмя одновременными сокетами и 5 секундами. Затем до четырёх маршрутов сравниваются **последовательно**, через отдельные Xray-процессы: HTTPS 204 и загрузка до 2 МиБ на маршрут. Общий бюджет проверки — 24 секунды. Если каталог пуст, перед ним пробуются основной адрес облака и CDN-зеркало с лимитом по 4 секунды.

Побеждает измеренная пропускная способность, а не минимальный пинг. Если доступность подтверждена, но замера скорости нет, интерфейс явно называет маршрут запасным. Прежнее соединение работает до выбора нового; отмена и смена сети не заменяют его. Для другого SOCKS-порта после переключения обновите настройки использующего прокси приложения: это ещё не прозрачный системный VPN.

Временная память результатов отделяется по сетевому контексту; ошибки HTTPS получают двухминутную паузу. Проверки не гарантируют самый быстрый сервер во всём каталоге или стабильную скорость в будущем. Автоматических изменений системного прокси и фоновых массовых скачиваний нет.
