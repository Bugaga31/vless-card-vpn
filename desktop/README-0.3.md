# Desktop preview 0.3.0 — Windows и Linux Mint

Это локальный SOCKS5-клиент с GUI, не полноценный системный VPN. Поддерживает VLESS TCP/raw + TLS/Reality; WS/XHTTP, WARP, TUN и Android-маски здесь не перенесены. Настройте выданный SOCKS5 в нужном приложении. HTTPS проверяется через отдельный процесс Xray; Telegram и трафик всего компьютера не подтверждаются.

- Windows 10/11 x64: запустите EXE, .NET и отдельный Xray устанавливать не требуется. EXE без подписи издателя; не отключайте системную защиту ради его запуска.
- Linux Mint 21+ / Ubuntu 22.04+ x64: установите `.deb` через менеджер пакетов либо `sudo apt install ./VLESS-Card-Desktop-0.3.0-linux-x64.deb`. Исполнение приложения от root не требуется. На CI проверен Ubuntu 22.04, не физический Mint.
- Альтернатива: распакуйте `.tar.gz` и запустите `vless-card/VLESS-Card-Desktop`. Системные библиотеки из зависимостей DEB должны быть установлены.

Импорт: VLESS-ссылки, base64-текст подписки или HTTPS URL (без редиректов, не более 2 МиБ). Публичное облако запускается только по кнопке, может быть недоступно или не иметь совместимых серверов. Авто ограничивает порцию проверки и сравнивает реальные пробы; это не Android-поиск без конца и не гарантия рабочего сервера. Повторное нажатие исследует следующую порцию. Ваши подписки не загружаются в репозиторий.

Ядро Xray v26.9.30 встроено на этапе сборки после проверки SHA256 официального архива. При старте извлекается в локальный профиль и проверяется по встроенному хешу; бинарники во время работы не скачиваются. Хеш не заменяет подпись издателя. SOCKS5 слушает только 127.0.0.1 со случайными логином и паролем. Копирование реквизитов — по вашей кнопке.

На Linux файлы сессий создаются с 0600 в каталоге 0700; штатное закрытие удаляет конфигурацию и завершает ядро. SIGKILL/авария питания не обеспечивают очистку: возможны оставшийся процесс и файл в ~/.local/share/VlessCard/sessions. На Windows процесс дополнительно привязан к Job Object. Системный proxy, DNS, маршруты и автозапуск не меняются.

Проверки: Core parser/selection regressions; конфигурационный запуск встроенного Xray с ожиданием exit code; открытие и штатное закрытие GUI на Windows runner и Ubuntu/Xvfb. Это не тест живого VPN у оператора, не тест устройств ARM/32-bit и не замер батареи.

Лицензии включены в EXE и пакет; `--licenses` выводит их текст (Windows GUI-EXE может потребовать перенаправление вывода). Исходники приложения и build workflow доступны в этом репозитории. Xray: https://github.com/XTLS/Xray-core/tree/v26.9.30 .
